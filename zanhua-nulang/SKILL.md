# 簪花女郎

把用户的简短设想扩写成可直接用于生图或图像编辑的中文提示词。目标是高完成度的中式幻想仕女人像，而不是笼统的“古风美女”。

每次使用前完整阅读 [references/style-guide.md](references/style-guide.md)。其中记录了这套风格的稳定视觉语法、可变项和常见失败。用户当轮的明确要求始终优先。

## 先确认任务模式

根据用户的实际目的选择一种模式：

1. **全新生图**：从零设计一位成年簪花女郎、动作、服装、场景和光线。
2. **参考图改写**：先看参考图，只把能确认的主体、姿态、构图和材质写入提示词；看不清的内容明确说无法确认。
3. **保形编辑**：锁定参考图中的脸、发型、冠饰、服装结构、动作、裁切和人物位置，只修改用户指定区域。
4. **直接生成或编辑**：用户明确要求出图时，先形成完整提示词，再调用当前环境可用的图像生成或编辑能力；没有可用能力时只交付提示词并说明限制。

“簪花女郎”在本 Skill 中是视觉风格名称，不代表特定朝代、地域或非遗项目。除非用户明确指定，不要擅自写成蟳埔簪花围、某朝代服饰复原、婚服或历史人物。

## 组织提示词

按以下顺序写成一个连贯文本，不要堆砌互相冲突的标签：

1. **镜头与画幅**：横幅或竖幅、景别、机位、主体所在分区、留白与前中后景。
2. **场景**：宫室花窗、花枝庭院、云海露台或用户指定环境，并交代空间冷暖和远近关系。
3. **人物**：成年东亚女性、神态、黑发造型、簪花冠饰、妆容、服装色块和材质。
4. **动作与道具**：回眸、闭目、抬袖、持横笛等；写清双手位置、视线和道具方向。
5. **光色**：单一方向的暖阳或逆光、冷色环境光、花影、轮廓光和受控高光。
6. **材质与成像**：丝缎、织锦、立体刺绣、薄纱、金属、珍珠和玉石各自呈现不同反射；主体局部清晰，背景和花冠形成分层虚化。
7. **负面约束**：只列与当前方案最可能发生的失败，覆盖结构、材质、构图和风格偏移。

## 核心约束

- 默认主体为一位成年女性。不要幼态化，也不要使用真实名人或可识别公众人物的脸，除非用户提供有权使用的本人参考并明确要求。
- 发冠是识别核心，但不能大到截断头部或吞没脸；花、金簪、珍珠、玉坠和流苏必须有可读的固定点、重力方向和前后遮挡。
- 金青配色来自孔雀青/蓝绿织锦、香槟金刺绣、暖象牙内衬和少量珊瑚红，不得用黄褐滤镜覆盖全图。
- 服装要有厚薄差异：织锦有重量，刺绣有凸起，薄纱半透明，金属和珠玉只在受光处闪亮。不要把所有材质生成成同一种塑料表面。
- 人脸保持柔和精致，但眼睛、睫毛、发丝和唇部边缘要清楚；允许轻微柔光和局部光晕，禁止全局磨皮、白雾和蜡像皮肤。
- 花枝、衣袖、横笛和肩线用于引导视线，不得遮住双眼或把主体切成不自然的碎片。
- 默认采用精致半写实数字人像和电影镜头质感，不谎称历史复原或真实摄影。用户要求真人摄影感时，再改用真实皮肤、镜头和服装制作语言。
- 有参考图时，不得凭风格名称覆盖用户原有脸型、姿态、人数、画幅或服装主色。

## 保形编辑

当用户说“人物不要变”“只换背景”“只加花影”时：

- 明确建议使用原图编辑、区域重绘或蒙版；普通重新生图无法可靠保持同一张脸。
- 提示词先写锁定项，再写唯一允许变化的区域。
- 蒙版避开发丝、流苏、手指、薄纱、刺绣边缘和透明饰品；必要时分区编辑。
- 不要在编辑提示词中重新设计人物全套造型，以免模型把主体整体重画。

## 输出格式

默认只给一套完成度高、可直接复制的中文结果：

```text
【主提示词】
完整、连贯的中文提示词

【负面约束】
针对当前构图与造型的具体失败项

【使用说明】
建议画幅、参考图或蒙版方式；没有必要时省略
```

用户指定模型时，只写该模型当前确认支持的参数。不确定参数、版本或权重时直接说不知道，不要编造。用户没有要求多方案时，不一次输出大量近似变体。
