# 簪花女郎

“簪花女郎”是一个中文生图提示词 Skill，用于把简短的人物设想或参考图改写成华丽、克制的中式幻想仕女人像。它重点控制簪花冠饰、珠玉金簪、金青重工织物、花影逆光、近景构图、道具路径和浅景深，避免只生成一张泛化的古风网红照。

## 能做什么

- 从一句话生成一套完整中文生图提示词和负面约束。
- 根据参考图提炼可见事实，并保持用户指定的脸、姿态、人数、服装主色和画幅。
- 为回眸、抬袖、持笛、云海露肩或闭目花枝等画面组织稳定构图。
- 在支持图像生成或编辑的环境中，配合提示词直接出图或局部修改。


## 输出与依赖

默认输出一套可直接复制的中文主提示词、针对性负面约束，以及必要的画幅或蒙版说明。用户明确要求直接出图时，仍需当前平台具备可用的图像生成或编辑能力。

本 Skill 本身不需要 API key，也不内置任何账号、密钥或固定模型参数。不同模型支持的参数可能变化，应以实际平台当前文档为准。

“簪花女郎”是本 Skill 的风格名称，不等同于特定朝代服饰、蟳埔簪花围、婚服或非遗复原。需要这些方向时，应由用户明确指定，再基于可靠资料调整。
