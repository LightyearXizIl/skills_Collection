# 生成式素材

只在真实动态镜头无法用代码或现有素材替代时使用。先确认用户允许使用的服务、预算、账号与素材用途；不要假定某个平台免费、已登录或已有 API key。

## 视频过场提示结构

```text
主体与动作：<一个清晰动作>
环境：<地点、时间、天气>
镜头：<景别、机位、运动方式>
视觉：纪实、自然光、低饱和、无文字、无品牌标志
时长与画幅：<秒数>，<16:9 或 9:16>
约束：单镜头、动作连续、避免形变、不要自动添加字幕
```

## 接入工程

1. 下载或导出后保留原始文件，不覆盖。
2. 放入 `public/clips/`，使用短而稳定的英文文件名。
3. 在场景配置中添加 `video: {src: 'clips/name.mp4', overlay: 0.35}`。
4. 默认将过场视频静音；需要原声时明确混音规则。
5. 实际渲染并检查首尾帧、循环接缝、编码兼容和授权范围。
