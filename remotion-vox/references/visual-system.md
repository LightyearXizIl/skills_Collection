# Vox 风格视觉系统

## 固定层级

1. 背景层：全片保持同一底色、纹理或单一共享背景图。
2. 中景层：黑白或低饱和半调 cutout，使用短促的弹入动画。
3. 前景层：数据、标签、箭头、建筑轮廓和流程框图。
4. 字幕层：短句、强对比、避免遮挡主信息。

## 默认视觉值

- 背景：暖白 `#F3EBDD`
- 深色：`#161616`
- 强调色：Vox 风格橙红 `#E4572E`
- 字体：优先使用系统可用的中文黑体栈；项目有授权字体时再改为本地字体文件。
- 构图：主体不要贴边；字幕与核心图表保留安全区。

这些值是模板默认值，不是用户品牌规范。用户提供品牌色、字体或参考图时，以其要求为准，并保持全片一致。

## 动画节奏

- cutout：`spring()` 弹入，多个主体按 0.1–0.25 秒错开。
- 图表：数值和几何形状使用同一帧进度；不要让数字先结束、柱体仍在增长。
- 打字机：使用字符串切片，不为每个字符创建独立透明度动画。
- 折线：用 SVG path 的 dash offset 或按点插值绘制，所有进度由当前帧计算。
- 退场只有在信息需要被替换时使用；不要每个元素都同时飞入飞出。

## Cutout 处理

- 原图保留不动，导出新的透明 PNG。
- 半调和黑白效果在图片阶段完成；Remotion 只做位置、缩放、弹入和偏移色描边。
- 自动抠图前先确认本地工具可用。边缘复杂、透明物体或毛发必须人工检查。
