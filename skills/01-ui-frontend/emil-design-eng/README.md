# emil-design-eng

来自 [emilkowalski/skills](https://github.com/emilkowalski/skills) 的设计工程综合 Skill，汇总 Emil Kowalski 对 UI 精修、组件、动画决策和细节品质的经验。

## 使用

```text
用 emil-design-eng 改善这个产品界面的完成度
用 Emil 的设计工程原则审查这个组件
```

它适合综合判断；需要动画实现、专项评审或全库规划时，优先使用更具体的同套 Skill。
