# fixing-accessibility

来自 [ibelick/ui-skills](https://github.com/ibelick/ui-skills) 的 Web 无障碍审查与修复 Skill，覆盖语义结构、ARIA、键盘操作、焦点、表单错误、对比度和动态内容。

## 使用

```text
用 fixing-accessibility 审查这个表单
修复这个对话框的键盘和焦点问题
```

应在现有技术栈内做最小修复，并优先验证真实键盘流程、焦点顺序、可访问名称和错误反馈；不能只靠静态规则声称符合 WCAG。

## 依赖与密钥

- Skill 本身不需要 API key。
- 自动化检查工具和浏览器测试按项目实际情况选用。
