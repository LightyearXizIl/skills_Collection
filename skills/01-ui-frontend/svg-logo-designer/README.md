# svg-logo-designer

独立编写的 Codex SVG Logo 设计技能，用于创建原创、可编辑、可缩放的 Logo 概念和变体，并检查 SVG 结构、安全性、可访问性与可移植性。

## 使用

```text
用 svg-logo-designer 为我的开发者工具做三个原创 Logo 方向
把选中的标志整理成横版、竖版、图标版和黑白版 SVG
检查这些 SVG 是否安全、可访问并适合上线
```

## 内容

- `SKILL.md`：品牌简报、概念开发、SVG 制作和交付流程
- `scripts/validate_svg.py`：检查 XML、viewBox、危险元素、外部资源、重复 ID 与可访问性元数据
- `agents/openai.yaml`：Codex 界面元数据
