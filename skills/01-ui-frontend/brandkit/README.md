# brandkit

来自 [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) 的品牌视觉板生成 Skill，用于把品牌策略、Logo 概念、配色、字体、数字/实体应用和图像方向组织成高完成度的品牌规范展示图。

## 使用

```text
用 brandkit 为企业 AI 助手做一张 3×3 品牌视觉板
为安全产品建立深色威胁情报风格的 Logo 与品牌应用方向
参考这些图片的节奏和质感，但不要复制现有 Logo
```

该技能输出的是品牌概念图和视觉方向，不等同于最终可注册商标、生产级矢量 Logo 或完整品牌规范手册。

## 依赖与密钥

- Skill 本身不包含 API key 或 token。
- 需要在支持图像生成的 Agent/模型中使用。
- 商标清查、字体授权、印刷色和最终生产文件需要另行验证。
