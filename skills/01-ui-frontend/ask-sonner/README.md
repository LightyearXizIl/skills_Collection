# ask-sonner

来自 [emilkowalski/skills](https://github.com/emilkowalski/skills) 的 Sonner React Toast 使用与排障 Skill。

## 使用

用 ask-sonner 修复这个项目的 Sonner Toast 不显示或重复显示问题。

它在需要精确属性与默认值时会读取同目录的 API.md。

## 依赖与许可

不需要 API key；目标项目需使用或准备安装 Sonner。固定来源提交：78761e1b57f97dce65b983d640c70a68f39e8163，采用目录内 MIT License。
