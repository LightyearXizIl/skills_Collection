# apple-design

来自 [emilkowalski/skills](https://github.com/emilkowalski/skills) 的 Apple 界面与流体动效原则 Skill，覆盖手势、弹簧、动量、中断、半透明材质、空间一致性、字体和 reduced motion。

## 使用

```text
用 apple-design 设计一个可拖拽并自然回弹的底部面板
审查这个界面是否正确运用了 Apple 风格的深度和动效
```

这些原则是面向 Web 的转译，不代表 Apple 官方实现或品牌授权；具体效果仍需在目标设备和浏览器中验证。
