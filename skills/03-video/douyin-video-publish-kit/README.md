# 抖音作品包装师

`douyin-video-publish-kit` 是一个面向抖音发布前包装的中文 Skill。它会分析用户提供的视频，整理可验证的画面事实，并生成 1 个推荐标题、2 个备选标题、可直接粘贴的作品描述、4–6 个相关话题标签，以及一张实际可用的 9:16 竖版海报封面。

## 使用

安装后提供待发布的视频并说明已知制作信息，例如：

```text
用抖音作品包装师分析这个视频，生成标题、作品描述、话题标签和 9:16 海报封面；制作模型是 MiniMax H3。
```

Skill 会先读取视频元数据和关键帧；只有对白、旁白或歌词确实影响文案时才需要转写。默认完成发布物料准备，不自动登录抖音、上传或公开发布。只有用户明确要求实际发布，且存在可用的已登录环境时，才进入上传操作。

## 依赖

- FFmpeg / FFprobe，用于读取视频信息和抽取关键帧。
- 可读取视频或图像的本地工具，用于建立事实卡和选择封面参考帧。
- 图像生成或编辑能力，用于制作实际的 9:16 海报。
- 音频转写能力仅在文案确实需要对白、旁白或歌词时使用。

本 Skill 不内置 API key，也不要求固定服务商。

## 内容边界

- 只写视频、用户说明或可靠元数据能够确认的内容，不臆造角色、剧情、地点、模型版本或合作关系。
- 模型或制作工具名称仅在用户明确说明或元数据能够可靠验证时使用。
- 不承诺“保证爆款”或“一定上热门”，发布物料质量不等于真实平台表现。
- 海报交付前需要检查文字、人物、手部、道具、裁切和比例，不能用提示词代替实际图片。
