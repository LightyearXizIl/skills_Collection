# 示例请求

```text
使用 story-asset-builder。
这是一个新项目，请先根据剧本创建 Project Profile，再创建 LibTV 资产准备画布。

项目名：《地下七小时》
类型：末日密闭空间悬疑短片

剧本：
男主醒来发现自己被困在地下储藏室，门外传来奇怪敲击声。房间里只有一台旧收音机、一瓶水、一盏快没电的应急灯。随着时间过去，他发现墙后面不是人，而是某种会模仿人声的东西。

要求：
1. 自动建立项目视觉规范
2. 拆解人物、场景、道具、怪物、分镜资产
3. 每个资产按工业化提示词文档格式生成完整 Prompt
4. 调用 LibTV 创建新项目和画布节点
5. 先只创建资产图节点，不直接生成最终视频
6. 所有节点必须放到画布上
```
