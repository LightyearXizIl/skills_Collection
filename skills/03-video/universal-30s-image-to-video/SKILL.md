# 通用图生视频时间线规范

把已定稿的静态图片资产，转成可直接使用的图生视频提示词。

## 路由

按目标时长选择模板：

| 目标 | 参考文件 |
|---|---|
| 30 秒 / 8 镜 | [references/30s-template.md](references/30s-template.md) |
| 15 秒 / 4 镜 | [references/15s-template.md](references/15s-template.md) |
| 5 秒单镜 | [references/5s-single-shot.md](references/5s-single-shot.md) |
| 武周题材 30 秒实例（含对白与音效节点） | [references/wuzhou-30s-example.md](references/wuzhou-30s-example.md) |

风格与画面基调由对应的美学 skill 决定（如 `$oriental-wuxia-natural-light-cinema`、`$wuzhou-visual-system`）；本 skill 只负责**时间、运动、声音与物理**。

## 铁律（违反即失败）

1. **严格参考输入图**：保持每张图中的人物身份、脸部、发型、服装颜色与材质、道具、环境与原始空间关系、光影方向和基础构图一致。
2. **全片正常速度**：严禁慢动作、子弹时间、速度渐慢、时间凝固、漂浮式仙气动作。
3. **空镜严格控时**：环境空镜统一 3 秒，不能因为「诗意」就拖成长镜。
4. **全部硬切**：无淡入淡出、无白闪、无粒子转场、无 AI 溶解。
5. **每镜结尾保留动作缓冲**：约 0.2–0.4 秒，人物动作与发丝衣料仍在余动，再切。
6. **同一人物不换脸**：全片保持同一张脸、同一年龄感、同一身体比例、同一头发长度。
7. **无 BGM、无字幕、无文字、无水印、无 Logo**。

## 风场设计原则

强化真实自然风，但**不同场景的风力必须有层级变化**，不能全片一个风。示例分层：

```text
高山 / 山巅 → 持续明显高山风
人物特写 / 看剑 → 中等侧风
村落空镜 → 晨间轻风
湖面空镜 → 持续湖风
竹林空镜 → 阵风穿林
室内读信 → 轻微窗风与雨气
雨窗 → 外部雨风 + 室内轻风
舟中 → 持续但柔和的湖面风
```

所有头发、衣袖、裙摆、云雾、炊烟、湖水、竹叶、纸页、雨滴都要符合**真实重力、空气阻力、延迟与回弹**。

## 物理质感清单

- 旋转产生惯性；衣物存在延迟；停止后产生余动。
- 布料有重量与垂坠感，甩开后自然展开再受重力回落。
- 水面波纹从受力点向外扩散并逐渐衰减。
- 纸张、帘幕、树叶等轻质物体响应风且回弹自然。
- 禁止机械动画感、CG 感、漂浮感。

## 输出结构（每个镜头）

```text
镜头N｜起止秒数｜镜头标题
{{Mixed N}}              ← 对应的参考图节点
焦段 + 景别 + 参考依据
起止时间内的动作拆解（正常速度）
环境与风的具体表现
运镜描述（幅度必须小于人物动作）
对白 / 旁白（如需要）
声音 / 环境声
结尾缓冲描述 + 硬切
```

## 声音设计

- 每镜给出具体环境声（风声、水声、脚步、衣料摩擦、纸页、烛火等），与环境一一对应。
- 若有人物台词，严格参考给定音效文件的音色、气息、停顿与情绪力度，口型需与字准确同步。
- 环境声必须低于人声，不加入背景音乐。

## 统一严格约束（附在提示词末尾）

```text
全片全部正常速度，严禁慢动作、子弹时间、速度渐慢、时间凝固；
空镜严格 3 秒，不得通过缓慢镜头拖长。
人物脸部必须始终稳定，不换脸、不变年龄、不改变五官比例；
手指数量正确，身体、衣服、道具不得穿模。
雨、水波、云雾、炊烟、竹叶、纸张全部符合真实物理。
无 CG 感、无 AI 油腻感、无 3D 渲染感、无动漫感、无游戏感、
无塑料皮肤、无蜡像脸、无过度锐化、无 HDR 感、无大面积黄金滤镜、
无灰雾压画面、无魔法粒子、无仙侠神光、无人悬浮、无轻功飞天、
无摄影机无意义环绕和高速乱晃。
```

## 节奏设计

整段必须形成一条可读的情绪路径，而不是镜头的堆叠。设计时先写出路径，再分配镜头。

例如武侠题材的一条完整路径：

```text
抬头看天地 → 低头看剑 → 看人间烟火 → 看山水 → 风起 → 回望过去 → 再次看向外面 → 继续前行
```
