### 2026-09-10 · Twilight 多视图实战（真实误判修正）
- 症状：v1 单张背面白底图分析时，把摄像头开窗内的 3+1+1 孔组判为壳体自带孔板（直接可见）。
- 根因：背面渲染图的开窗内合成了展示手机的镜头模组；单视图无法区分"壳体孔板"与"透过贯通开孔可见的展示物"。
- 规则补丁：见 02-analysis-rules.md §L 新增条目——开孔内可见物体必须与正面/内面视图对照；贯通开孔内的镜头模组属展示物，禁止写入壳体结构。
- 归属：02-analysis-rules.md §L（通用规则）

### 2026-09-10 · 流沙壳首次实战（Twilight 18 Pro Max）
- 症状（预判）：AI 把夹层亮片画成表面印刷、或把沉淀态画成全壳均匀铺满。
- 根因：母版默认所有结构固定，未区分「固定结构」与「动态内容物快照」；亮片被当作表面纹理处理。
- 规则补丁：内容物分层逻辑/密度趋势/亮片类型/色调必须锁定；单颗位置允许变化；亮片必须写为夹层内悬浮物，有真实深度。已固化至 02-analysis-rules.md §R。
- 归属：02-analysis-rules.md §R（通用规则）

### 2026-09-22 · 实拍图「精修 / 去毛屑」需求（编辑模式首次实战）
- 症状（预判并已在提示词中预防）：用户拿一张实拍产品图只要求"去毛屑"，若提示词只写"清理灰尘纤维"，生成式编辑器会顺手重绘产品——典型后果：① 透明壳的摄像头**贯通开窗**被画成实心面板；② 环支架的 **C 形缺口被补成完整闭合圆环**；③ **环形丝印被拉直**成横排文字或重新排版；④ **LED 闪光灯模组的颗粒状内部纹理被当作灰尘擦掉**；⑤ 透明壳被全局提亮/平滑成"崭新塑料"。
- 根因：编辑类提示词只写了"删什么"，没有把母版的识别特征与禁止项**转译为「保留锁定」**；且低分辨率下，产品自带的颗粒状纹理（闪光灯 LED、拉丝金属、织物织纹、透明件内应力纹）与灰尘**同形**，模型无法自行区分。
- 规则补丁：见 02-analysis-rules.md §S——编辑模式提示词必须成对写 `REMOVE`（只删瞬时缺陷）+ `MUST PRESERVE`（逐条锁定第 13/15 段），并把"外形像灰尘的产品纹理"显式点名禁删。
- 归属：02-analysis-rules.md §S（通用规则）

### 2026-09-22 · 用户给「目标样张」说"精修成这样，场景保留"（参考图角色判定）
- 症状（需预防）：用户贴一张同款产品的干净样张作为目标，若把该参考图当作"结构/场景来源"，模型会顺手把样张的场景与零件布局搬过来——典型后果：① 用户原图的**织物台面被替换成样张的光滑浅色台面**；② 原图的**斑驳树影被抹平**成均匀柔光；③ 样张的**镜头排布/零件数量被套用到用户产品**（若两者是不同版本即为凭空改结构）；④ 把样张的**水印、UI 边框、裁切比例**一起画进去。
- 根因：没有给参考图定性。参考图与用户原图**不同源**：一个是"目标观感"，一个是"待修素材"，二者角色不能混。
- 规则补丁：见 02-analysis-rules.md §S 新增条目——参考图定性为 **look reference**（只取影调、光比、材质锐利度、清洁度、白平衡倾向）；结构以**用户原图**为唯一依据；场景要素（台面材质与纹理、光影图案、投影方向、背景元素）写入 SCENE LOCK 并显式禁止替换；参考图的水印/UI 边框/裁切比例列入禁止项。
- 归属：02-analysis-rules.md §S（通用规则）

## 规则补丁

### 2026-09-10 · 初始候选规则（待实战校验）

以下为创建 skill 时预置的候选规则，尚需真实案例验证。每次实际使用后发现其有效/失效，直接在本条下追加验证结论，勿删原文。

- **症状**：母版写好后，换一个镜头角度生成，产品前后端互换。
- 根因：母版只用"前/后"字样，未给功能端的物理定义与画面锚点。
- 规则补丁：母版首句必须锁定「功能端 = X（具体物理特征）」，并紧跟一句画面锚点交叉说明。
- 归属：02-analysis-rules.md §B

- **症状**：唯一零件（单侧接口、单侧旋钮）被生成成左右各一个。
- 根因：只写了"禁止生成错误结构"，未给数量与随体坐标。
- 规则补丁：凡唯一零件，必写「某侧数量 = N，对侧数量 = 0」并显式禁止镜像复制。
- 归属：01-master-prompt.md（已含，执行时不得省略）

- **症状**：支架被生成成"贴着主体的装饰条"，路径丢失。
- 根因：只描述了颜色与材质，未给连续路径。
- 规则补丁：支架一律按「起点 → 方向 → 弯曲点 → 经过哪一侧 → 终点接地」五段式写，并给截面与弯曲半径比例。
- 归属：02-analysis-rules.md §K

- **症状**：网罩/格栅被渲染成一块灰色平面。
- 根因：未建立深度层级，AI 把纹理当表面图案。
- 规则补丁：网罩必须写成可透视的四层结构，并写明开孔形态与孔壁可见性。
- 归属：02-analysis-rules.md §G

- **症状**：暖光下的黑色机身被写成"深棕色机身"。
- 根因：环境反射色混入固有色。
- 规则补丁：固有色段落禁用环境描述；反射偏移单独写在环境反射层。
- 归属：02-analysis-rules.md §I

- **症状**：Logo 位置在每张图都不一样，或文字被重新排版。
- 根因：按画面空间描述位置，未用表面局部 UV。
- 规则补丁：丝印位置一律用"某外表面 + 距某端的长度占比 + 距某边的宽度占比 + 排版方向 + 字头朝向"描述。
- 归属：02-analysis-rules.md §J

- **症状**：爆炸图/内部件被当成正常外观，生成时内部件外露。
- 根因：未区分拆解展示件与正常可见件。
- 规则补丁：内部件段落必须显式标注「拆解展示件，正常状态不可见」。
- 归属：02-analysis-rules.md §P

- **症状**：分析结果里混入了资料图上的尺寸标注、箭头、标题文字。
- 根因：OCR 式地把图上所有文字当成产品丝印。
- 规则补丁：识别文字前先区分"资料图层"与"产品表面层"；标注/箭头/标题一律排除。
- 归属：01-master-prompt.md（已含，执行时不得省略）

### 2026-09-22 · 「精修编辑」模式的提示词结构（通用）

- **症状**：用户要的是"修图"而不是"生成图"，但提示词仍按"生成"写，导致模型重绘产品身份（贯通开窗变面板、C 形缺口闭合、环形丝印拉直、自带颗粒纹理被清除）。
- **根因**：编辑模式缺少"只删不改"的约束骨架；且未区分「瞬时缺陷」与「产品自带颗粒纹理」。
- 规则补丁：编辑模式提示词固定四段式 —— `TASK（只清洁，不重绘不重打光不重构图）` → `REMOVE（逐条列瞬时缺陷）` → `HOW TO CLEAN（像素局部修补、继承周边表面；禁全局平滑/模糊/降噪/提亮；禁改任何边缘与高光线）` → `MUST PRESERVE（把第 13 段识别特征 + 第 15 段禁止项逐条转写，并点名"外形像灰尘的产品纹理"）`。环状/弧面丝印另加一句"不追求逐字精确，疑义处保持原样而非重绘"。
- 归属：02-analysis-rules.md §S（通用规则）

### 2026-09-22 · 用户反馈「材质表现不好，要像 3D 渲染那种」（任务类型升级）
- 症状：提示词改到"黑更黑白更白 + 加微对比 + 提清晰度"，用户仍反馈材质扁平无体积感。
- 根因（关键）：**问题不在影调参数，在任务类型**。当时提示词含 `not a re-render` 与 `still clearly my photo, not a synthetic render` 两句，**明确禁止模型重做材质**，只能"搬像素 + 提对比"。纯像素编辑路径下材质必然偏平、偏糊，无论怎么调参都到不了 CGI 级。
- 规则补丁：当用户说"材质不行 / 要 3D 渲染感"时——
  1. 先检查提示词里有无禁重绘措辞（`not a re-render` / `not a synthetic render` / `keep it a photo`），**有则必删**；
  2. 把任务升级为 **产品区域重渲染（re-render product region only）**，背景仍锁为原照片；
  3. 新增逐面 PBR 材质清单：透明件 = 折射实体 + clearcoat 细锐连续高光 + Fresnel 边缘提亮 + 折射位移；哑光件 = 低粗糙度缎面 + 宽而平滑的渐变高光 + **每道机加工倒角一道细亮锐利高光**（CGI 最标志性特征）；金属 = **各向异性**拉丝（高光沿拉丝方向拉成条带）+ 连续 HDRI 环境渐变；镜片 = 真实光学进深 + AR 镀膜反射；全局 = 干净 AO + 正确接触阴影 + 物理合理反射 + 零噪点/零色散/零压缩伪影/产品上无景深虚化；
  4. 反向声明 `DO NOT interpret "smooth / clean / no noise" as permission to erase real surface micro-grain` —— 防"去噪"被理解为"磨平材质颗粒"。
- 术语响应：Gemini / nano-banana-pro 对 `Cinema 4D / Octane / Redshift / Blender Cycles / KeyShot / PBR / clearcoat / anisotropic / HDRI` 响应良好，可放心使用。
- 归属：02-analysis-rules.md §S（通用规则）

### 2026-09-22 · 重渲染把机身 LOGO / 丝印抹掉（表面图形硬保留）
- 症状：升级为产品区域重渲染后，用户反馈"手机本身的 LOGO 不要消失不见"。
- 根因：重渲染时模型把机身上的丝印 / 文字当作**表面纹理**一并重画并覆盖；且 `REMOVE` 段"清除所有瑕疵"的指令与之相冲突，只加一句"保留 LOGO"会被反制。
- 规则补丁：**三处同时钉桩**才稳——
  1. 在材质段单列一条 `SURFACE GRAPHICS`：正面要求重渲染时必须**再画出来**，同形 / 同位 / 同尺寸 / 同朝向；
  2. 在 `REMOVE` 段加 `EXPLICIT EXCEPTION`：声明 LOGO / 字标 / 型号 / 法规标记属"表面图形"而非瑕疵，不受"清除所有痕迹"管辖；
  3. 在 `MUST PRESERVE` 与 `AVOID` 各追加一条同义锁定（AVOID 中用全大写加强）。
  并追加**反向禁令**：`never INVENT or ADD a logo or text that is not visible in the source` —— 手机类产品有强先验，重渲染时容易凭空补一个不存在的 LOGO；若某标记落在裁切之外，应保持"无"，不得补画。
- 归属：02-analysis-rules.md §S-2（通用规则）

### 2026-09-22 · 实拍图里带品牌包装盒 / 印刷品（盒面文字事故）
- 症状（需预防）：实拍产品图常把**零售包装盒**一起拍进去。若只写"保留场景"，模型会顺手**重排、补全、翻译、美化盒面文字**，典型后果：① 被裁切的品牌字标被"补全"成完整拼写；② 无法辨认的小字被"锐化"成另一组词；③ 凭空多出认证标 / 图标 / 参数；④ 橙色版式被重排、字号被放大。
- 根因：把包装盒当成普通背景道具，未意识到盒面是**受版权与事实双重约束的印刷图形**，且小字号在编辑模型中属最高乱码风险区。
- 规则补丁：实拍图内含包装盒 / 吊牌 / 说明书 / 印刷卡时，必须——
  1. 把盒面**全部文字、字标、徽标、配色、版式**列入 `MUST PRESERVE`，并写明"被裁切的字标保持裁切状态，不得补全"；
  2. 加 `AVOID`：`rewriting or completing illegible box text` + `INVENTING TEXT, LOGOS OR MARKS NOT PRESENT IN THE SOURCE`；
  3. 交付时提示用户：该区域**不追求逐字精确**，需要逐字正确应后期单独处理。
- 归属：02-analysis-rules.md §S-4（通用规则）

### 2026-09-22 · 光面产品的大面积环境倒影（属摄影内容，须用户决策）
- 症状（需预防）：光面机身 / 光面壳上出现**大面积室内倒影**（拍摄者轮廓、房间、灯具）。若提示词只写"清理干净"，模型可能把倒影整段抹成纯黑（丢真实感），或反过来**编造一个新环境**贴在倒影里（更糟：把背景包装盒镜像进倒影）。
- 根因：倒影是**摄影内容**（依 §L 反射 ≠ 结构），既可保留也可清理，**属需求侧决策而非结构事实**，不能默认处理。
- 规则补丁：出现大面积环境倒影时——
  1. 在锁定清单里**单列一条**，标明"属摄影内容，不是产品结构"；
  2. 给用户**两个可选方向**并说明差异：保留真实倒影但清理脏斑 / 替换为干净的影棚渐变反射；
  3. 无论选哪种，都必须在提示词中写明 `keep a real reflection PRESENT（光面必须反射）`，并**禁止编造倒影内容、禁止把背景道具镜像进倒影**（`do NOT mirror the box/background into the reflection`）。
- 归属：02-analysis-rules.md §S-5（通用规则）

### 2026-09-23 · 屏幕面视角实拍图（翻转 + 点亮 双重翻车）
- 症状（需预防）：实拍图拍到的是**屏幕面朝上**、背面摄像头与环支架完全不可见。若提示词仍按"这个产品有摄像头 + 环支架"来写，模型会：① **把机身翻过来**或在本视角**凭空补画背面摄像头模组 / 环支架**；② 把"提升质感"误读为**点亮屏幕**，加出壁纸 / 状态栏 / 图标 / 时间；③ 把面板上的极小开孔放大或复制成多个；④ 把壳体侧边的棱纹增减或填平。
- 根因：产品身份（有摄像头、有环支架）与**本视角可见内容**是两回事。母版锁定的是"产品有什么"，本视角要锁的是"这一面朝上、另一面不可见"；且玻璃面板的"质感提升"极易被误执行成"提亮 / 加内容"。
- 规则补丁：见 02-analysis-rules.md §S-6——① 锁朝向 + 明写禁翻转、禁补画背面部件；② 熄屏锁定（禁 UI / 壁纸 / 状态栏 / 时间 / 文字，并在 AVOID 重复一次）；③ 开孔与棱纹的**数量 + 间距**锁定，禁放大与增减；④ 同一产品的不同视角图**各自独立锁定**，不互推部件画面方位。
- 归属：02-analysis-rules.md §S-6（通用规则）

### 2026-09-23 · 画面中倒置的印刷内容（AI 会"把字摆正"）
- 症状（需预防）：产品与包装盒被物品遮挡或相机旋转，导致盒面文字在画面中**呈倒置 / 侧置**。模型有强"把文字摆正"倾向，会主动旋转、重排甚至改写。
- 根因：只写了"保留盒面文字"，未锁定**朝向**。
- 规则补丁：见 02-analysis-rules.md §S-4 第 6 条——凡画面中倒置 / 侧置的印刷内容，必须写明"保持原有朝向，不得旋转扶正、不得重排"，并在 `AVOID` 加 `rotating upright`。
- 归属：02-analysis-rules.md §S-4（通用规则）

### 2026-09-23 · 精修把机身 LOGO"修没了"（去瑕误伤 + 反向禁令被误读）
- 症状：用户反馈"现在精修都把 LOGO 修没了"，并要求核对"手机壳与手机 LOGO 处的遮挡关系"；实际关系是**苹果 LOGO 被环带遮挡约一半**。
- 根因（双重）：
  1. `REMOVE ALL usage traces / 清除所有使用痕迹` 会把机身背面那处**微弱、低对比**的 LOGO 当作污渍 / 痕迹一并擦除 —— **LOGO 越微弱越容易被当成瑕疵**；
  2. 我方为防"凭空加 LOGO"写的 `never INVENT or ADD a logo not visible in the source`，被模型读成**"本图没有 LOGO"**，反而成为删除既有 LOGO 的依据。
- 次级根因（分析侧）：因单视图看不清，此前版本把它写成"未见机身 LOGO / LOGO 未入镜 / 无法确认"，进一步强化了"不存在"的结论。**带 MagSafe 环的机型，LOGO 默认落在环内孔范围内并与环带部分重叠，属存在项。**
- 规则补丁：见 02-analysis-rules.md §S-7（LOGO 推定位置 + 四层遮挡层级 + 可见/隐藏分割条款 + 微弱观感条款 + 去瑕豁免），并同步收窄 §S-2 的反向禁令（只禁"新增额外标记"，不禁保留既有 LOGO）。
- 归属：02-analysis-rules.md §S-7（通用规则）

### 2026-09-23 · 品牌字标是"变体字"，我全程写错了拼写（Λ 被当成 A）
- 症状：用户指出"**文字 logo 也要保护好，不要动它 `MΛGEΛSY`**"。此前提示词全程写作 `MAGEASY`。
- 根因：**把品牌名按常识补全成常规英文拼写**——实物的第 2、6 位是**尖角 Λ（开口倒 V、无横杠）**，不是字母 A。而提示词里写 `MAGEASY` 等于**主动指示模型把 Λ 画成 A**，与"保护字标"的目标正好相反。附带错误：盒面可见的字标尾部我原先读作 `ASY`，实为 `ΛSY`（其左的 `E` 被画面裁切）。
- 规则补丁：见 02-analysis-rules.md §S-8——逐字符列位次 + 字形描述；显式禁止"规范化/补全"；加 `Treat any output where Λ has become A as a failed result.` 失败判据；多载体（环带丝印 / 壳体模压字 / 盒面印刷）分别锁定；被裁切字标保持裁切；**拼写一律以用户确认为准**。
- 归属：02-analysis-rules.md §S-8（通用规则）

### 2026-09-23 · 修正 LOGO 后模型把它"重新居中"（位置条款必须写在可见性之前）
- 症状：按上一条修正（"LOGO 存在、被环带遮挡约一半"）重跑后，用户反馈"**这个 logo 位置不对，应该是被遮挡的**"——输出里 LOGO 被摆到环内孔中部、完整可见；同时镜片玻璃被修成**浅绿发亮**（我方"AR 镀膜反射"条款被过度执行）。
- 根因：修正条款把重点放在"**保留 + 微弱**"，却没有锁**位置**。模型于是先挑一个"最好看"的位置（环内孔正中）再"保持微弱"——结果本该被环带遮挡的下半部被画成完整可见，遮挡关系丢失。
- 规则补丁：见 02-analysis-rules.md §S-7 第 9–10 条——**位置条款必须紧接在 LOGO 存在性之后、可见性条款之前**；位置要写"环内孔偏下部、被环带下段重叠"，并明禁"居于中部/上部""在孔内完整可见"；可见性写"不得比原图更可见/更大/更锐/更亮"；`AVOID` 加"relocating / re-centring / placing a clear centred logo"。另：`faint AR reflection` 须补 `the glass stays DARK`，防镜片变浅绿。
- 归属：02-analysis-rules.md §S-7 第 9–10 条（通用规则）
