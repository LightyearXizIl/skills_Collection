# 15 段输出骨架与自检清单

严格按此顺序输出，段号与标题固定，不得缺段、合并、换序。

---

## 1. 产品核心识别总结
3–5 句：这是什么产品、什么形态、最关键的一眼识别点。不展开细节。

## 2. 信息可信度
列出本次资料清单（视图类型与数量），并给可信度总评（高/中/低 + 原因），说明哪些结论建立在「合理视觉判断」之上。

## 3. 产品自身坐标
定义 前端 / 后端 / 顶部 / 底部 / 自身左侧 / 自身右侧，各一句判定依据；再给一句画面锚点交叉说明。若无明确前后端，改用 正面/背面、长边/短边、上表面/下表面。

## 4. 整体几何与比例
主体形态分类 → 比例关系（比值或真实尺寸）→ 体态判断词。

## 5. 主体结构逐件拆解
按层级从外到内、从前到后列表。每件一件一段，必写 10 项（数量/形状/尺寸比例/位置/朝向/前后顺序/安装方式/连接关系/凹凸或悬空/遮挡关系）。组件编号 `P-xx` 全篇唯一。

## 6. 关键连接与空间拓扑
法线方向、高低极值位置、前后错位关系、唯一零件的数量与坐标、深度层级（最外层 → 透明层 → 内部结构 → 更后层）。

## 7. 控制件 / 接口 / 丝印
每件给 5 要素：是什么 + 哪个实体表面 + 局部坐标 + 相邻部件 + 排版方向。左右相似件分别定义。

## 8. 支架与接地结构
连续路径：起点 → 方向 → 弯曲点 → 经过哪一侧 → 终点接地；截面、弯曲半径、包胶位置。无支架则写「本产品无支架结构（直接可见）」。

## 9. 材质 PBR 分区
按部件分区，每区 6 项：粗糙度 / 镜面响应 / 高光宽度 / 反射连续性 / 表面纹理 / 透明关系。无法确认基材时用「视觉上呈现为……」。

## 10. 固有色与工作状态分离
分三块写：固有色 / 环境反射色（允许的偏移）/ 工作发光色（归入可变项）。

## 11. 无法确认结构
逐条列出，格式为 `结构名 — 原因（被遮挡 / 分辨率不足 / 视图冲突）`。此段允许为空，但段标题必须保留。

## 12. 最容易生成错误的位置
针对本产品预判 3–8 处，每处写「现象 + 触发原因 + 规避写法」。

## 13. 产品关键识别特征
5–10 条，每条一句话，只收高判别力结构。

## 14. 唯一产品母版提示词
一段连续可复制的提示词，按 `最高权重锁定 → 产品自身坐标 → 整体比例 → 主体结构 → 前后/上下关键部件 → 独特拓扑关系 → 控制件与丝印 → 支架/连接件 → PBR 材质响应 → 固有色 → 工作状态允许变化 → 必要禁止项` 组织。用围栏代码块包裹，便于直接复制。

## 15. 针对性必要禁止项
逐条、具体、绑定部件与坐标的禁止清单，5–12 条。

## 交稿前自检清单（逐条打勾后再输出）

**依据与真实性**
- [ ] 全篇未出现本次资料之外的产品结构
- [ ] 所有未确认结构均已标注「无法从当前资料确认」，无补造
- [ ] 未出现"通常为""一般为""应该是"式的隐性补造
- [ ] 无虚构的毫米级尺寸（无真实尺寸时只用比例）

**坐标与镜像**
- [ ] 全程使用产品自身坐标，未混用画面左右
- [ ] 已给出画面锚点交叉说明
- [ ] 唯一零件已写明数量与产品自身坐标

**几何与结构**
- [ ] 无"简洁/科技感/高级/流线型"等替代几何的概括词
- [ ] 每个关键部件 10 项属性完整
- [ ] 圆角/曲率用了可约束表达，无"大圆角""柔和曲面"
- [ ] 多视图冲突已标注为"疑似不同版本/不同结构"
- [ ] 透明件/网罩已建立四层深度层级，无透视穿帮

**材质与颜色**
- [ ] 材质按部件分区，未整件一个材质词
- [ ] 每区 6 项 PBR 特征齐备
- [ ] 无法确认的基材写的是"视觉上呈现为……"，未断言牌号
- [ ] 固有色 / 环境反射色 / 工作发光色已分离

**控制件与丝印**
- [ ] 每个控制件与丝印给了 5 要素，含"印在哪个实体表面"
- [ ] 左右相似件已分别定义并禁止造型互换
- [ ] 无法辨认的文字未猜写
- [ ] 资料图中的标注/箭头/标题未被误当丝印

**摄影与结构分离**
- [ ] 未把高光当零件、阴影当凹槽、反射当孔洞、背景当产品色

**母版与禁止项**
- [ ] 第 13 段 5–10 条均为高判别力特征，无形容词凑数
- [ ] 第 14 段按 12 项顺序组织，无空泛词
- [ ] 第 15 段只留模型真正易犯的错误，无机械重复正文

**格式**
- [ ] 15 段齐全、顺序正确、段标题一致
- [ ] 全程未生成任何图片
