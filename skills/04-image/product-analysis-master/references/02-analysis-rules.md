# 判读执行细则

母版（`01-master-prompt.md`）规定"要什么"，本文件规定"怎么判断、怎么写"。

---

## A. 可信度四级判定标准

| 级别 | 判定条件 | 书写格式 |
|------|----------|----------|
| 直接可见 | 在任一视图中清晰成像、轮廓完整、无遮挡 | 直接陈述，不额外标注 |
| 多视图相互印证 | ≥2 个视图（或视图+细节图）指向同一结构且不冲突 | `（正视图 + 45°视图互证）` |
| 合理视觉判断 | 单视图可推、符合透视与投影关系，但无第二视角 | `（合理视觉判断：……）` |
| 无法确认 | 被遮挡 / 分辨率不足 / 视图冲突 / 完全未入镜 | `无法从当前资料确认` |

**硬规则**：第 4 级只写"无法确认"，**禁止**写"可能是""通常为""一般为"然后继续按该结构描述。疑似推断一律降级到「合理视觉判断」并显式标注，或归入第 11 段「无法确认结构」。

## B. 产品自身固定坐标系（防镜像、防前后互换）

建立顺序：

1. **定功能端**：先找功能端（出风口/出光口/镜头/出风口/喷嘴/按键面/接口面/刃口/握持端）。功能端 = **前**。
2. **定轴线**：主体几何长轴 = 前后轴；不能确定时改用「正面/背面」+「长边/短边」+「上表面/下表面」。
3. **定上下**：与重力/放置面相关的面 = **底**；其对立面 = **顶**。无放置信息时用"上表面/下表面"。
4. **定左右（关键）**：采用**随体坐标** —— 假想观察者站在产品**后端**、沿前进方向朝**前端**看，其左手侧 = **产品自身左侧**，右手侧 = **产品自身右侧**（等同船舶左舷/右舷规则）。
5. **给画面锚点**：第 3 段必须再给一句交叉说明，例如「产品自身右侧在正视图中位于画面左侧」，避免下游 AI 按画面空间重新排版。
6. **统一不改名**：后续所有旋钮、Logo、接口、支架、丝印、进/出风口一律用随体坐标书写，**全篇不得改用画面左右**。

## C. 整体几何与比例

- 先给主体形态分类词：圆筒 / 方箱 / 圆角矩形 / 薄板 / 柱体 / 异形壳体 / 复合结构（可组合，如"圆角矩形主体 + 圆筒功能端"）。
- 再给比例关系：用**比值**而非绝对值，如「长:宽:高 ≈ 3:1.6:1」「直径约为长度的 0.45」。
- 再给体态判断词：短厚 / 细长 / 扁平 / 超薄 / 厚重（只选一个主词，可加一个修饰）。
- 有真实尺寸时：写「长×宽×高 = A×B×C（对应产品自身前后×左右×上下）」，并以此覆盖比例估算。

## D. 圆角 / 倒角 / 曲率描述词汇表

禁止用：大圆角、柔和曲面、圆润过渡、流线型、科技感曲面。

采用以下可约束表达：

- 圆角相对短边比例（如「圆角半径约为短边的 1/6」）
- 连续圆角 / 变半径圆角 / 等半径圆角
- 大半径浅弧 / 小半径深弧
- 低曲率凸面 / 低曲率凹面 / 平面化
- 曲率渐变 / 曲率突变（并指明突变位置）
- 边缘收弧 / 边缘倒角（写清倒角面数与大致角度区间，如"约 45° 单面倒角"）
- 是否存在切线突变（是/否 + 位置）
- 是否形成阶梯（是/否 + 阶数 + 每阶大致高差比例）

无法获得真实 R 值时用相对比例，**不写工程毫米数**。

## E. 逐件拆解：每件必写 10 项

`数量` · `形状` · `尺寸比例` · `所在位置` · `朝向` · `前后顺序` · `安装方式` · `与相邻部件的连接关系` · `凸起/内凹/悬空` · `遮挡关系`

**层级命名规范**（不得混写成一个"组件"）：
主体外壳 / 端框 / 网罩 / 内部模块 / 顶壳 / 控制盒 / 控制座 / 旋钮 / 锁紧件 / 支架 / 脚套 / 把手 / 紧固件 / 装饰条 / 面板 / 镜片 / 灯罩 / 接口座。

每件编号唯一（如 `P-07 侧面锁紧旋钮`），全文引用同一编号，便于后续迭代只改单件。

## F. 多视图交叉验证分工

| 视图 | 主要职责 |
|------|----------|
| 正视图 | 整体轮廓、左右布局、对称关系 |
| 侧视图 | 厚度、前后坐标、堆叠顺序 |
| 45°视图 | 部件空间连接、凹凸关系、装配顺序 |
| 背视图 | 后侧真实结构（铭牌、接口、进/出风、支架根部） |
| 俯/仰视图 | 顶面/底面控制件与脚垫分布 |
| 细节图 | 接缝、圆角、曲率、丝印、纹理、紧固件类型 |

冲突处理：先记录冲突点与涉及视图 → 判为「疑似不同版本/不同结构」→ **分别描述两个版本**，禁止融合。

## G. 空间拓扑与深度层级

- 必写法线方向：沿外法线向外凸 / 向内凹 / 与外表面齐平 / 悬空。
- 必写极值位置：「中央为最高点、向四周连续降高」「最高点偏向前端 1/3 处」。
- 唯一零件必写数量与坐标，例如「后侧数量 = 1，前侧数量 = 0」「仅位于产品自身左侧，右侧数量 = 0」，并禁止镜像复制。
- 透明件/网罩四层顺序：**最外层 → 保护层/透明层 → 内部结构 → 更后层结构**。禁止：内部元件贴面、网罩变灰平面、实体外壳被透明化、透视穿帮。

## H. PBR 材质分区

按部件分区，禁止整件一个材质词。每区写清 6 项：**粗糙度倾向 / 镜面响应强弱 / 高光宽度 / 反射连续性 / 表面纹理 / 透明或半透明关系**。

常用材质视觉判定：

| 材质 | 视觉特征 |
|------|----------|
| 喷粉金属 | 中高粗糙度、漫反射为主、宽而弱的高光、反射不连续、细颗粒感 |
| 烤漆金属 | 低粗糙度、锐利窄高光、反射连续、可见清晰环境倒影 |
| 裸金属（拉丝/阳极） | 各向异性拉丝纹、沿纹理方向拉长的高光、中等反射 |
| 工程塑料 | 中等粗糙度、柔和宽高光、反射弱、可见细微橘皮或咬花 |
| 橡胶/包胶 | 极高粗糙度、几乎无镜面、高光极宽且暗、哑光 |
| 玻璃 | 高透过率 + 强镜面 + 边缘全反射 + 可见厚度与折射位移 |
| 透明塑料 | 透过率高但反射弱于玻璃、常见内应力纹 |
| 扩散材质 | 半透、内部散射、无明显镜面、边缘透光更强 |
| 木纹饰面 | 方向性纹理、低反射、随纹理起伏的弱高光 |
| 织物 | 结构性强、完全无镜面、纤维方向可见 |

**断言规则**：真实基材无法确认时写「视觉上呈现为……」，不得断言材料牌号（如"6063 铝""ABS"）。

## I. 颜色三层分离

| 层 | 内容 | 写法 |
|----|------|------|
| 固有色 | 产品本体在中性光下的颜色 | 写入第 10 段与母版"固有色"项 |
| 环境反射色 | 受环境/灯光影响的反射偏移 | 只写"在 X 光下出现 Y 反射"，不改写固有色 |
| 工作发光色 | LED/热光/气流/火焰/雾/粒子 | 写入"工作状态允许变化"，禁止并入固有色 |

判别例：黑色机身 + 暖光 → 仍是黑色机身，仅出现暖灰/暖棕反射；黄色金属支架在暖环境中 → 固有色仍为黄色；红色辉光 ≠ 红色本体。

## J. 控制件 / 接口 / 丝印 / 刻度

每件必须同时给出 5 要素：**是什么 + 在哪个实体表面 + 局部坐标位置 + 与哪个部件相邻 + 排版方向**。

- 位置按**表面局部 UV 布局**写（如"位于顶壳表面、距前端约 1/5 长度处、水平居中"），不按画面空间。
- 排版方向写清：横排/竖排/沿弧面环绕/与某边平行/字头朝向功能端。
- 无法辨认的文字不猜；只描述"存在一组 N 个字符的丝印，字符内容无法辨认"。
- 左右两个外形相似但功能不同的控制件 → **分别编号、分别定义造型**，并显式禁止造型互换。
- 远侧被遮挡的零件 → 写"按照真实遮挡隐藏"，不得为对称而露出。

## K. 支架 / 提手 / 脚架 / 框架路径追踪

必须给**连续路径**：起点连接点 → 延伸方向 → 弯曲位置与角度 → 经过主体哪一侧（随体坐标） → 终点接地/结束位置。

并写清：圆管/方管、截面尺寸比例、弯曲半径（相对比例）、包胶位置与长度占比。

反例（禁止）："黄色支架"——无路径、无截面、无起止点。

## L. 摄影效果 ≠ 产品结构（判别清单）

- 高光 ≠ 银色零件
- 阴影 ≠ 黑色凹槽
- 反射/倒影 ≠ 透明孔洞或开口
- 背景色 ≠ 产品颜色
- 摄影棚反光板、柔光罩倒影 ≠ 产品表面结构
- 后期 Glow / Bloom / 光晕 ≠ 产品发光件
- 景深虚化 ≠ 曲面渐变
- 接缝处的暗线 ≠ 独立零件
- **透过开孔/透明区可见的展示物 ≠ 产品结构**：白底渲染图常在开孔内合成展示假机（如手机镜头模组）。判断方法：对照正面/内面视图——若开孔贯通无孔板，则孔组属于展示物，不得计入产品本体；只有装机图才允许出现该展示物。

## M. 关键识别特征筛选（第 13 段）

选 5–10 条，筛选标准：**删掉它，AI 就会生成另一个产品**。

优先候选：主体比例 / 功能端前后关系 / 独特控制模块 / 唯一凸起或唯一内凹 / 边框曲率 / 支架路径 / 材质分区边界 / 单一零件的唯一数量与坐标 / 标志性丝印位置。

不收：颜色、氛围、"科技感"、材质手感等低判别力形容词。

## N. 唯一母版提示词组段顺序（第 14 段）

`最高权重锁定` → `产品自身坐标` → `整体比例` → `主体结构` → `前后/上下关键部件` → `独特拓扑关系` → `控制件与丝印` → `支架/连接件` → `PBR 材质响应` → `固有色` → `工作状态允许变化` → `必要禁止项`

语言要求：工业设计 + 产品摄影的可执行语言。**禁用**：高级、科技感、电影感、精致、未来感、质感好等无法约束几何的词。

## O. 禁止项选取原则（第 15 段）

只写**模型真正容易犯**的错误，逐条针对本产品的具体部件与坐标，不写通用套话。

高频候选：前后端互换 / 左右镜像 / 唯一零件被重复生成 / 关键部件被删除 / 多层结构融合成一体 / 支架路径被改变 / 控制件造型互换 / 隐藏件穿透主体 / 材质同质化 / Logo 或丝印位置错误 / 擅自增加按钮、显示屏、底座、把手、轮子、螺丝、散热孔。

已在正文明示且 AI 不易误解的，不在禁止区机械重复。

## P. 内部件图 / 爆炸图处理

- 内部件与整机的可见位置必须对应（写清对应到哪个外表面之下、第几层）。
- 单独展示 ≠ 正常状态外露。必须区分「拆解展示件」与「正常外观可见件」。
- 禁止把拆解件贴到整机外侧。

## R. 动态内容物（流沙 / 液体 / 悬浮颗粒 / 可动件）

母版默认结构固定，但流沙壳、液体瓶、可滑动件等产品的"内容物分布"是**当前快照状态**，不是固定结构。处理规则：

- **锁定层（写入母版）**：分层逻辑（如沉淀在底部）、密度分布趋势（上稀下密）、亮片/颗粒的类型与形状（星形/六边形/圆点）、混色构成、渐变方向与色调。
- **不锁定层（标注可变）**：单颗亮片/颗粒的精确位置与角度、沉淀堆的微观轮廓。
- 母版写法：先写「沉淀态参考分布」，再在"工作状态允许变化"项中声明内容物可自由流动，但**不得改变分层逻辑与色调**。
- 悬浮颗粒是**夹层内容物**，禁止写成表面印刷贴纸；必须写明夹在两层透明板之间、有真实深度。
- 状态描述需标注：本图为「沉淀静置态」；摇晃后分布会变（合理视觉判断，除非资料另有说明）。

## S. 实拍图精修 / 编辑模式（REMOVE + MUST PRESERVE 成对约束）

当用户不是要"生成"而是要"修"一张已有实拍图（去毛屑 / 去灰尘 / 去指纹 / 去杂物）时，母版规则不变，但输出物不是产品母版，而是**编辑约束提示词**。写法固定为四段：

1. `TASK`：明确这是一次只做清洁的编辑——不重绘、不重新打光、不重新构图、不换背景，保留原图取景、透视、曝光、白平衡、色调、阴影方向与光影图案。
2. `REMOVE`：只列**瞬时缺陷**（毛屑纤维 / 灰尘颗粒 / 松落杂物 / 指纹油污薄雾 / 轻微搬动痕迹），逐条绑定出现位置（哪个部件的哪个表面）。
3. `HOW TO CLEAN`：要求**像素局部修补、继承周边表面**（透明件清完后仍要看得到后面的结构；拉丝金属保留各向异性纹；织物保留织纹与褶皱）。**显式禁止**全局平滑、模糊、降噪、提亮、去噪美颜、以及改动任何边缘位置、边缘厚度与高光线。
4. `MUST PRESERVE`：把第 13 段识别特征与第 15 段禁止项**逐条转写为保留锁定**，不得只写"保持产品不变"。

硬规则：

- **必须点名"外形像灰尘的产品纹理"不得清除**：LED 闪光灯模组的颗粒/晶格内部纹理、拉丝或喷粉金属的颗粒感、织物织纹、透明件内应力纹与边缘高光。低分辨率下这些与灰尘同形，不点名就会被擦掉。
- **贯通开窗、C 形缺口、环形/弧面丝印、唯一零件的数量与坐标**，在编辑模式下同为硬锁定项：开窗不得被画成实心面板，缺口不得被补成闭合环，弧面丝印不得被拉直或重排版。
- 弧面/环形小字丝印另加一句：**不追求逐字精确，存在疑义时保持原样，不得重绘或重新排版**。
- 单视图仍适用 §L：透过开窗可见的手机镜头模组属展示物，编辑时不得当作壳体孔板改动。
- 编辑模式下只给提示词，不做结构重推（避免把已确认结构从单张实拍图重新猜一遍）。
- **用户提供「目标样张」时（如"精修成这样，场景保留"）**：必须给参考图定性为 **look reference** —— 只取影调、光比、材质锐利度、清洁度、白平衡倾向；**结构以用户原图为唯一依据**，不得套用参考图的零件布局与数量（两者可能是不同版本）；**场景以用户原图为准**，须写成 `SCENE LOCK`（台面材质与纹理、光影图案与位置、投影方向、背景元素），并显式禁止把参考图的台面材质 / 机位 / 水印 / UI 边框 / 裁切比例搬入画面。若参考图带来的差异属场景或布光层面（如把织物台面换成光滑浅色台面、把斑驳光影压成均匀柔光），必须单独标出并请用户确认，不得混在"精修"里默认执行。

### S-1. 模式升级：从「只清洁」到「产品区域重渲染」（3D 渲染质感）

当用户反馈"产品材质表现不好 / 要像 3D 渲染那种"时，判为**任务类型问题，不是影调参数问题**：

1. **先排查自锁**：旧提示词若含 `not a re-render`、`still clearly my photo, not a synthetic render`、`keep it a real photo` 一类**禁重绘措辞，必须删除**——它们会把模型锁死在"搬像素 + 提对比"路径，材质必然扁平。
2. **升级任务**：改为 `RE-RENDER THE PRODUCT REGION ONLY at photoreal CGI / 3D-render quality`，**背景仍为原照片**（BACKGROUND stays the original photograph），保持取景 / 透视 / 裁切 / 分辨率不变。
3. **新增 PBR 材质清单**（逐面给，不得只写"提升质感"）：
   - 透明件：折射实体 + 可见壁厚 + Fresnel 边缘提亮 + 折射位移 + clearcoat 细锐**连续**高光 + 大平面上的柔和 HDRI 面板反射。
   - 哑光件：低粗糙度缎面 + **宽而平滑**的渐变高光 + **每道机加工倒角一道细亮锐利高光**（CGI 最标志性特征）+ 表面渐变数学级干净、无噪点。
   - 金属：**各向异性**拉丝 —— 高光必须沿拉丝方向**拉成条带**（不是圆点）+ 连续 HDRI 明暗渐变 + CNC 锐利圆边。
   - 镜片：真实光学进深 + 微弱 AR 镀膜反射（蓝紫/青）+ 同心阶梯 bezel 各带独立微粗糙度。
   - 扩散件：半透 + 内部散射 + 边缘透光更强。
   - 全局：干净 AO、正确接触阴影、物理合理反射（只反射可信环境，不凭空造物）、零噪点 / 零色散 / 零压缩伪影 / 产品上无景深虚化。
4. **必配反向闸**：`DO NOT interpret "smooth / clean / no noise" as permission to erase the product's REAL surface micro-grain` —— 防"去噪"被误解为"磨平拉丝颗粒 / LED 颗粒纹理 / 织物织纹"。
5. 术语可用：`Cinema 4D / Octane / Redshift / Blender Cycles / KeyShot / PBR / clearcoat / anisotropic / HDRI / Fresnel / IOR`。

### S-2. 表面图形（LOGO / 字标 / 丝印）硬保留 + 反向禁令

重渲染会把机身上的丝印当作**表面纹理**重画并覆盖，属高频事故。只加一句"保留 LOGO"无效（会被 `REMOVE` 的"清除所有瑕疵"反制），必须**三处同时钉桩**：

1. 材质段单列 `SURFACE GRAPHICS`：正面要求重渲染时必须**再画出来**，**同形 / 同位 / 同尺寸 / 同朝向**。
2. `REMOVE` 段加 `EXPLICIT EXCEPTION`：声明 LOGO / 品牌字标 / 型号文字 / 法规认证标记属**表面图形，不是瑕疵**，不受"清除所有痕迹"管辖。
3. `MUST PRESERVE` 与 `AVOID` 各追加一条同义锁定（AVOID 中用全大写加强）。

**反向禁令（同样必须写）**：`never INVENT or ADD a logo or text that is not visible in the source`。手机、笔记本、家电类产品有极强先验，重渲染时极易凭空补一个不存在的 LOGO；若某标记落在裁切之外，应保持"无"。
另：透明壳下的丝印应保留"隔壳轻微折射偏移"但仍清晰可读。

**⚠️ 反向禁令必须收窄（2026-09-23 实测事故后修订，务必执行）**：只写 `never INVENT or ADD a logo or text that is not visible in the source` 会被模型读成「本图没有 LOGO」，从而**把机身原本存在的微弱 LOGO 一并清除**。正确写法必须**同时**给出正反两面：
- 正面：`The phone's logo IS present — keep it at the same position / size / orientation / faint appearance`；
- 反面（收窄）: `Do not invent any ADDITIONAL logo, text or certification mark not present in the source. (This forbids ADDING new marks — it is NOT a licence to delete the existing logo.)`
详见 §S-7。

### S-3. 结构锁定复核（编辑/重渲染前的必做步骤）

用户要求"先分析锁定原图结构"时，交付**结构锁定清单 + 编号示意图**，逐部件写：部件名 / 数量 / 相对排布 / 尺寸比例 / 材质外观事实 / 锁定要点。并强制包含：

- **与既往版本的差异更正**：每次复核都要与上一版提示词逐条比对，凡位置、数量、规格写错的，显式列出「原写 → 实测 → 更正」。
- **画面方位描述**：环状件断口、开口等易错结构，除随体坐标外再给**画面钟点方位**（如"环带右侧、画面约 3 点钟"），降低下游理解歧义。
- **不确定项只锁外观事实**：如"无镜面反光的暗色圆件"，只锁数量 / 位置 / 无反光三项，**不推断功能**（依 §L）。
- **反向检查"该有的有没有"**：既要列出图中有、不许消失的；也要列出**图中没有、不许编造**的（如裁切外的 LOGO）。

### S-4. 实拍图内含品牌包装盒 / 印刷品（盒面文字硬保留）

实拍产品图常把**零售包装盒、吊牌、说明书、印刷卡**一并拍入。盒面是**受版权与事实双重约束的印刷图形**，且极小字号在编辑模型中属最高乱码风险区。规则：

1. 盒面**全部文字、字标、徽标、配色、版式、位置**一律写入 `MUST PRESERVE`。
2. 明确写"**被画面裁切的字标保持裁切状态，不得补全**"（AI 极易把裁切字补成完整拼写）。
3. `AVOID` 必加：`rewriting / re-lettering / completing illegible box text`、`INVENTING TEXT, LOGOS OR MARKS NOT PRESENT IN THE SOURCE`。
4. 交付时必须提示用户：该区域**不追求逐字精确**；需要逐字正确应出图后单独后期处理。
5. 盒面**不得**被当作"背景杂乱"而移除或模糊——它属场景锁定项。
6. **画面中呈倒置 / 侧置的印刷内容必须保持其原有朝向**：写明"保持倒置状态，不得旋转扶正、不得重排"。AI 有强烈的"把文字摆正"倾向，只写"保留文字"不够，必须显式禁止旋转与扶正。

### S-5. 光面产品的大面积环境倒影（属摄影内容，须用户决策）

光面机身 / 光面壳上出现**大面积室内倒影**（拍摄者轮廓、房间、灯具）时：

1. 在锁定清单里**单列一条**，并标明"属摄影内容（依 §L 反射 ≠ 结构），不是产品结构"。
2. 给用户**两个可选方向**并说明差异：① 保留真实倒影但清理脏斑；② 替换为干净的影棚渐变反射。**不得默认替用户决定**。
3. 无论选哪种，提示词都必须写明 `keep a real reflection PRESENT`（光面必须反射，不得整段抹成纯黑）。
4. 必加禁令：**不得编造倒影内容**，**不得把背景道具（如包装盒、桌面）镜像进倒影**（`do NOT mirror the box/background into the reflection`）。

### S-6. 屏幕面 / 正面视角（熄屏锁定 + 禁止翻转）

当实拍图拍到的是产品的**屏幕面（正面）朝上**、而背面部件（摄像头、支架、铭牌）不可见时，必须：

1. **锁定朝向**：明写"屏幕面朝上、背面朝下且本图完全不可见"，并加禁令 `do NOT turn the product over / do NOT reveal or add the rear camera module, lens barrels or ring stand anywhere in this view`。AI 有强烈倾向"把没露出来的标志性部件补画出来"，这是本类图最高频的翻车点。
2. **熄屏锁定**：若屏幕为熄屏黑，必须明写 `the screen MUST stay switched off: pure deep black, no wallpaper, no icons, no status bar, no clock, no notifications, no on-screen text, no UI of any kind`，并在 `AVOID` 中重复 `SWITCHING THE SCREEN ON or adding any wallpaper/icons/status bar/clock/text`。**不得**把"提升质感"误解为"提亮屏幕 / 让屏幕有内容"。
3. **光面反射**：屏幕玻璃为光面，反射处理同 §S-5（保留真实倒影但清理脏斑；禁止编造倒影内容、禁止镜像背景道具）。
4. **开孔与棱纹**：面板上的极小开孔（前置摄像头 / 传感器）与壳体侧边的棱纹 / 齿状结构的**数量与间距**必须锁定，并禁止"放大开孔""增减棱纹""把棱纹填平"。
5. 若同一产品同时有"背面视角图"与"屏幕面视角图"，两图**必须各自独立锁定**，不得互推部件位置（视角旋转会改变部件的画面方位）。

### S-7. 机身 LOGO 的推定位置与遮挡层级（环支架机型专用，通用判读）

**推定（默认成立）**：带**环支架 / MagSafe 环**的手机产品，机身 LOGO 通常落在**环的内孔范围内**，且往往**与环带部分重叠**（被环带遮挡一部分）。因此：

1. **不得因"单视图看不见"就判为"无 LOGO"**。低分辨率或掠射角下 LOGO 观感极弱，但它属**存在项**。凡环内孔内可见任何低对比浅色 / 反光图形，优先推定为 LOGO（标注「合理视觉判断」），并写入硬保留项。
2. **必须写出层级关系**（依 §G 四层规则）：`环带（不透明金属，最近）→ 透明壳（透明层，带自身表面反射）→ 机身背面（LOGO）→ 机身内部（不可见）`。
3. **必须写"可见/隐藏分割"条款**：`Keep the EXACT visible/hidden split — the same portion visible through the ring's inner opening, on the same side, at the same size and orientation; the same portion hidden behind the band.` 并明禁：移动 / 放大 / 旋转 / 重新居中 LOGO 以"露出"它；改变环内孔径或环带宽度；把被遮挡部分透过金属显示出来。
4. **必须写"微弱观感"条款**：LOGO 是隔壳隔孔看到的**低对比、略带反光**的痕迹；**不得提亮成明显白标**、不得锐化成硬边图形、不得提升到壳面、不得画到环带之上。
5. **去瑕段必须豁免它**：`This logo is NOT dust / smudge / scratch / noise — never remove, erase, fade, bleach or crop it.`（`REMOVE ALL usage traces` 类指令是本类事故的第一诱因。）
6. 与 §S-2 的反向禁令**配套使用**：正面声明"存在且保留" + 反面只禁"新增额外标记"。

7. **遮挡关系是"结构"的、配色是"可变项"的（切勿混为一谈）**：LOGO 与环带的遮挡关系（LOGO 位于环内孔偏下、被环带下段与卡扣横切）属**结构事实**，**同一产品的不同配色 SKU 完全一致，按"通用"处理**；随图变化的只有**环的配色**（紫色 / 银色 / 黑色…），按各图锁定、不得改色。**不得因配色不同就把它判为"不同版本/不同结构"而放宽锁定**（依 §F：仅配色差异 ≠ 版本差异）。
8. **推定的普遍性**：本类"环支架 + LOGO 被环带部分遮挡"的形态在带 MagSafe 环的产品中高度常见，**凡环带与机身品牌图形在视线上重叠者，一律先按"部分遮挡"处理并写明可见/隐藏分割**；只有多视图证明"完全不重叠"时才改为"完整可见"。

9. **重渲染破坏 LOGO 的三种方式（逐条设防）**：① **抹除**（去瑕逻辑误伤 → 见第 5 条）；② **移位 / 重新居中**——模型会"顺手"把 LOGO 摆到环内孔正中央，使本该被环带遮挡的部分变成完整可见；③ **提亮 / 放大**——把微弱 LOGO 修成清晰白标。设防写法**必须先位置、后可见性**：
   - 位置：`reproduce the logo at the SAME POSITION the source shows — inside the ring's inner opening, OFFSET TOWARD THE LOWER PART, where the ring band's lower segment overlaps it. It must NOT sit in the middle or the upper part of the opening, and must NOT be drawn fully visible inside the opening.`
   - 可见性：`Never make it MORE visible, larger, cleaner or more contrasty than the source; if the source barely shows it, keep exactly that faint trace — do not invent a newly visible logo.`
   - 并在 `AVOID` 加：`relocating / re-centring / re-scaling that logo inside the ring's opening`、`placing a clear centred logo inside the ring's opening`、`making the logo more visible or more contrasty than the source shows`。
   **顺序不能反**：只写"保持微弱对比度"会让模型先把 LOGO 摆到最好看的位置、再"保持微弱"——**位置错了，一切皆错**。
10. **AR 镀膜反射必须限强度**：写 `faint multi-coat AR reflection (subtle blue-violet / teal tint)` 时，模型易产出**浅绿 / 发亮的镜片玻璃**，而实物是**深色玻璃、仅边缘微弱镀膜色**。必须补 `the glass stays DARK, the AR tint must remain subtle`，并在 `AVOID` 加 `light, bright, milky or saturated green lens glass`。

**事故复盘（2026-09-23，同日两轮迭代）**：① 用户反馈"精修都把 LOGO 修没了"——根因是 `REMOVE ALL usage traces` 误擦微弱 LOGO + 旧版反向禁令被读成"本图无 LOGO"；② 修正后又反馈"**logo 位置不对，应该是被遮挡的**"——根因是模型把 LOGO **重新居中**到环内孔中部、使其变成完整可见。**结论：位置条款必须写在可见性条款之前（第 9 条），并须同时设防第 10 条的镀膜过亮。**

### S-8. 变体字标（符号替换 / 合体字）——逐字符锁定，禁止"规范化"

品牌字标常故意以符号或变体字形替换字母（实例：**`MΛGEΛSY`** —— 第 2、6 位用**尖角 Λ**（开口倒 V、**无横杠**）代替字母 A）。凡遇到此类字标：

1. **逐字符列出并标注位次**：`M · Λ · G · E · Λ · S · Y`；明确指出**第几位被什么符号替换**（第 2、6 位 = Λ，**不是 A**），并给**字形描述**（开口倒 V / 无横杠 / 无水平笔画）。
2. **显式禁止"规范化"**：`never normalise, simplify, correct or auto-complete the Λ glyphs into A; never respell, re-typeset, re-space, restyle, translate or rewrite the wordmark`。**只写"保留原拼写"不够**——模型会按"正确英文"自动改回 A。
3. **加显式失败判据**：`Treat any output where Λ has become A as a failed result.`（实测此类"判定句"的约束力明显强于单纯禁止）。
4. **同一字标的多载体分别锁定**：环带丝印（沿弧排版、字头朝环心）、壳体模压字、包装盒印刷（正立）——**各处字形、位次、朝向分别锁定，并以同一拼写为准**；弧排版本**禁止拉直**。
5. **被裁切的字标保持裁切**：若画面只露出字标尾部（如盒面只露 `ΛSY`，其左的 `E` 被裁切），必须写明"**保持裁切状态、不得补全**"，并禁止把被裁切的半个字画成完整字。
6. **拼写一律以用户确认为准，不得按品牌名常识补全**（本次事故即源于提示词写作 `MAGEASY`、实物为 `MΛGEΛSY`）。

**事故复盘（2026-09-23）**：用户指出"文字 logo 也要保护好，不要动它 MΛGEΛSY"。此前提示词全程写作 `MAGEASY`，与实物不符 → 模型会照提示词把两个 Λ 画成 A。**逐字符核对是唯一防线。**
