# 卷五：现代 · 当代时装人像

> 这是时间轴的当代端（Clean Modern），与卷四的"新中式"是不同档：
> **新中式 = 当代场景 + 中国元素**；**本卷 = 当代场景 + 当代时装**，不含传统元素。
> 若你要的是"现代 + 中式"，请看卷四的新中式章节。

## 现代与古风的核心差异（先看这条）

古风靠"氛围与质感"取胜，**现代靠"精确与干净"**——因为观者每天看真人，任何一点不真实都会被立刻察觉。

| 维度 | 古风/民国 | 现代 |
|---|---|---|
| 画质 | 允许胶片颗粒、褪色 | **干净锐利**，颗粒只在刻意复古时用 |
| 光影 | 大光比、戏剧化 | **精确布光**（蝴蝶光/伦勃朗光/分割光），或干净自然光 |
| 面料 | 丝、罗、锦、绒 | 精纺羊毛、棉、针织、皮革、丹宁、涤纶混纺——**工业质感要准** |
| 剪裁 | 平面裁剪、垂坠 | **立体剪裁**，肩线、驳头、腰省必须清晰 |
| 皮肤 | 保留毛孔即可 | 还要**虹膜纹理、眼白微血管、唇纹、发际线绒毛** |

## 六个分支

### A. 都市职场（通勤）

- **形制**：西装（单排/双排扣）、衬衫、针织衫、风衣、直筒西裤、公文包；版型挺括，肩线清晰
- **面料**：精纺羊毛、府绸棉、真丝衬衫、羊绒；注意**羊毛的哑光 vs 真丝的柔光**差别
- **场景**：写字楼大堂、电梯间、会议室、街道转角、地铁站台
- **光影**：窗光 + 反光板补面，或棚拍蝴蝶光；**冷白偏中性**，干净利落
- **色调**：低饱和冷灰、藏青、白、驼色；轻微青蓝阴影
- **常见错误**：肩线塌陷、驳头糊成一团、领带歪斜；场景混入老物件

### B. 时尚杂志（棚拍硬光）

- **形制**：设计感服装、廓形外套、高定礼服、夸张配饰；姿态有张力
- **光影**：**硬光源**（裸灯/雷达罩）+ 黑旗控光，形成明确阴影边界；或色片打彩色光
- **色调**：高对比，可大胆用单色背景（红、钴蓝、荧光）
- **常见错误**：把杂志片拍成"证件照"——必须有姿态张力和明确的光型逻辑

### C. 日常街拍（自然光胶片感）

- **形制**：卫衣、T 恤、牛仔、帆布鞋、棒球帽；松弛、不刻意
- **光影**：自然光（树荫、墙边反光、黄金时刻逆光），**允许过曝一点**
- **色调**：柯达 Portra 暖调 / 富士淡青调；可有轻微颗粒
- **常见错误**：姿态摆拍痕迹重；背景杂乱抢主体

### D. 礼服 / 婚纱（优雅向）

- **形制**：晚礼服、缎面长裙、西装礼服、头纱；面料以缎、纱、丝绒为主
- **光影**：逆光勾勒轮廓 + 柔光补面，或大柔光箱高调
- **色调**：低饱和高级灰、香槟金、纯白高调
- **常见错误**：缎面高光糊成一片；头纱透明度失真

### E. 运动休闲（动态）

- **形制**：运动背心、速干衣、leggings、跑鞋；**汗湿**是真实感关键
- **光影**：强烈侧光或逆光表现肌肉线条与汗珠
- **色调**：高明度、高饱和，健康感
- **常见错误**：肌肉结构不真实；汗珠像油；运动鞋结构错乱

### F. 都市夜景（霓虹 / 赛博感）

- **形制**：皮衣、风衣、休闲西装、街头服饰
- **光影**：霓虹招牌作主光 + 车灯光轨 + **湿地面镜面反射**；大光比
- **色调**：青橙对比（teal & orange），或品红 + 青的赛博配色
- **常见错误**：霓虹糊成色块；人脸在暗部完全丢失细节（**必须用反光板逻辑补面**）

## 现代专属的"反 AI 味"补充条款

古风那套必写子句依然有效，现代另外要加：

```
眼睛有清晰的虹膜纹理与眼神光，眼白有细微血丝，唇部有唇纹，
发际线有细小绒毛与碎发，指甲有自然甲面光泽与甲缘，
衣物有真实版型结构（肩线、驳头、省道、缝线清晰可见）
```

**现代必须规避的变形重灾区**：手（十指）、眼镜（镜腿/镜片反光）、手表、耳机、拉链、鞋带、文字 logo（会生成乱码字）。

## 通用负面提示词（现代专用补充）

在通用负面提示词基础上追加：

```
肩线塌陷，驳头模糊，版型松垮，领带歪斜，拉链错位，鞋带错乱，
眼镜变形，镜腿错位，手表指针错乱，耳机结构错误，
乱码文字，错误logo，内衣肩带穿帮，
证件照式僵硬姿态，影楼磨皮，背景杂乱抢主体
deformed glasses, broken watch hands, garbled text, wrong logo,
sloppy shoulder line, passport photo pose, messy background
```
