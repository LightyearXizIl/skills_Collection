# 历代衣冠 · 全时代写实人像提示词生成

> 覆盖先秦 → 秦汉 → 魏晋南北朝 → 隋 → 唐 → 五代十国 → 宋 → 辽金西夏 → 元 → 明 → 清 → 民国 → 新中式 → 现代 → 仙侠玄幻，共 15 个时代档位。

## 适用场景

生成**看起来像真实照片**的国风人物（汉服 / 古风），人物为虚构形象。不支持把真实人物照片转为国风（那是图生图 + 肖像授权问题，见文末边界说明）。

## 核心原则（决定成败的三条）

1. **写实感来自"缺陷"**。真实皮肤有毛孔、细小绒毛、轻微不对称、眼下细纹。凡是让画面变"塑料"的词一律不写：`完美肌肤、无瑕、磨皮、 porcelain skin、flawless、airbrushed`。必须反向写明 `保留皮肤质感，可见毛孔与细小绒毛，不过度磨皮`。
2. **朝代形制要具体，不能只写"汉服"**。"汉服"是泛称，模型会乱混朝代。必须锁定具体形制（如"明制竖领对襟衫 + 马面裙"），形制、配色、发型、妆容互相匹配。
3. **光影决定质感，镜头决定真实**。国风最忌"影楼平光"。指定单一主光源方向 + 光质（窗光/逆光/烛光）+ 具体焦段（35/50/85mm）+ 光圈。

## 提示词六段式结构

按此顺序拼装，缺哪段补哪段，顺序不要乱：

| 段 | 内容 | 必备程度 |
|---|---|---|
| 1 主体 | 年龄、性别、脸型、五官特征、肤色、表情、姿态 | 必备 |
| 2 服饰 | 朝代 + 具体形制 + 面料 + 纹样 + 配色 | 必备 |
| 3 发妆 | 发式、发饰、妆容（贴合朝代） | 必备 |
| 4 环境 | 场景、背景元素、景深虚化程度 | 必备 |
| 5 光影 | 光源方向、光质、色温、光比 | 必备 |
| 6 技术参数 | 焦段、光圈、画质、色调、胶片特性 | 必备 |

**"反 AI 味"子句单独附在第 6 段后**，见下节。

## 反 AI 味关键写法

必写（复制即可）：

```
写实摄影风格，真实皮肤质感，可见毛孔与细小绒毛，轻微肤色不均，不过度磨皮，
自然微表情，眼神有焦点，衣物有真实垂坠与褶皱，环境有细微灰尘与光斑
```

必避免：

```
完美无瑕 / 磨皮 / 塑料感 / 过度锐化 / HDR / 发光皮肤 / 十根手指畸形 /
纹样对称到失真 / 发丝糊成一坨 / 背景过度虚化成色块
photorealistic 8k masterpieces 之类的堆词（堆词无效，反而拉低质量）
```

## 全时代速查表

> 详细形制（面料、纹样、发式、妆容、场景、常见错误、完整提示词）见下方参考卷，**按需读取，不要一次全读**。

| 时代 | 核心形制 | 主色 | 发型/首服标志 | 最容易错的点 |
|---|---|---|---|---|
| 先秦 | 上衣下裳、深衣、冕服（玄衣纁裳） | 玄、纁、赤 | 冠、笄、垂髻、双鬟 | 无扣无立领；冕冠按等级有旒数 |
| 秦汉 | 曲裾深衣、直裾（襜褕）、袍、襦裙 | 玄、赤、纁、青 | 长冠/进贤冠、堕马髻、步摇 | 右衽方向；西汉曲裾不露足 |
| 魏晋南北朝 | 褒衣博带大袖衫、杂裾垂髾、袴褶 | 尚白、玄、青 | 纶巾、木屐、灵蛇髻、飞天髻 | 是飘逸不是华丽；飘带只在下摆 |
| 隋 | 窄袖短襦 + 高腰长裙、幞头圆领袍 | 素净偏淡 | 软脚幞头 | 别直接套盛唐齐胸大袖 |
| 唐 | 齐胸襦裙、圆领袍、半臂、披帛 | 朱红、石青、金（唐三彩系） | 高髻、堕马髻、插梳、花钿 | 裙头系胸上；初唐≠盛唐 |
| 五代十国 | 承晚唐渐内敛，展脚幞头出现 | 过渡期 | 硬脚/展脚幞头 | 气质是过渡与收敛 |
| 宋 | 褙子、宋抹、百迭裙、直裰 | 月白、藕荷、天青（淡雅） | 低盘发、东坡巾、珍珠妆 | 淡妆；不是"保守版唐制" |
| 辽金西夏 | 髡发/辫发、圆领窄袖袍、蹀躞带 | 皮褐、深青 | 髡发、皮靴 | 别写成宋制 |
| 元 | 质孙服、辫线袄、**罟罟冠** | 金、红、蓝（重织金） | 婆焦、钹笠帽、罟罟冠 | 罟罟冠限贵族已婚妇女 |
| 明 | 竖领对襟衫、马面裙、比甲、道袍、曳撒 | 藏蓝、赭石、墨绿、大红 | 狄髻+头面、方巾网巾 | 马面裙≠百褶裙；补子有品级 |
| 清 | 旗装（氅衣、马褂）**与**汉女袄裙**并行** | 石青、枣红、湖色 | 两把头 / 晚清大拉翅、花盆底鞋 | 清旗装≠民国旗袍；大拉翅只是晚清 |
| 民国 | 改良旗袍（收腰包臀）、长衫、西装 | 酒红、墨绿、藏蓝、阴丹士林蓝 | **手推波纹**、礼帽 | 别混古代形制；光影要低照度高对比 |
| 新中式 | 马面裙日常化、香云纱、宋锦外套 | 米白、藏青、低饱和 | 现代发型 + 木簪 | 元素做减法，忌堆砌 |
| 仙侠玄幻 | 非历史体系，唐宋明底子自由改造 | 依设定 | 半束发、散发 | 别与真实朝代考据混用 |
| 现代（当代时装） | 西装、风衣、针织、牛仔、礼服、运动装 | 依分支（冷灰 / 暖胶片 / 青橙夜调） | 现代发型，**无传统元素** | 版型与配饰易变形；画面要干净锐利 |

### 高频时代精简要点

**唐**：齐胸襦裙 + 圆领袍 + 半臂 + 披帛；联珠纹、宝相花、团窠；高髻插梳、花钿面靥斜红；配色浓烈。
**宋**：褙子 + 宋抹 + 百迭裙；宋锦缂丝、生色花、折枝；低盘发、珍珠妆；配色淡雅。
**明**：竖领对襟衫 + 马面裙 + 比甲；妆花织金、补子；狄髻 + 银鎏金头面（分心/挑心/掩鬓）；配色沉稳。
**民国**：改良旗袍（高立领、盘扣、收腰包臀）+ **手推波纹**；钨丝灯 3000K 主光 + 霓虹轮廓光 + 烟雾光束；teal & orange。
**新中式（当代 + 中国元素）**：香云纱 / 宋锦 / 马面裙日常化；元素做减法；干净自然光。
**现代（当代时装）**：立体剪裁 + 精确布光（蝴蝶光 / 伦勃朗光 / 硬光）+ 干净锐利画质；与新中式的区别是**不含中国元素**。

## 工作流程

1. **问清 4 个变量**：时代（对照全时代速查表，含民国/新中式/仙侠）、性别、氛围（清冷/华丽/庄重/市井/烟火）、景别（特写/半身/全身）。不要一次问太多，缺失的用默认值补齐并在输出时说明。
2. **信息不足时读参考卷**：唐 / 宋 / 明 / 民国可直接用本文件的速查表与示例；**其他时代（先秦、秦汉、魏晋、隋、五代、辽金西夏、元、清、新中式、现代、仙侠）必须先读取对应 `references/` 文件**，再按该卷的形制、纹样、发式、妆容、场景符号与"常见错误"生成。一次只读一卷。
   - 注意区分**新中式（卷四）**与**现代（卷五）**：前者是当代场景 + 中国元素，后者是当代场景 + 当代时装、无传统元素。用户说"现代"时若语意含糊，先确认是哪一档。
   - 卷五含 6 个分支（职场 / 杂志 / 街拍 / 礼服 / 运动 / 夜景），分支未指定时先问，或默认"职场"。
3. **按六段式拼装**输出中文提示词，附英文关键词串与画幅参数。
4. **主动询问是否直接出图**——用户确认后调用图像生成工具出图，不要未经确认就生成（消耗额度）。
5. 出图后若不满意，按优先级调整：先改光影 → 再改时代形制 → 最后改五官描述。

## 边界说明

- **不生成真实存在的人物**（公众人物、用户亲友的照片转国风）。涉及肖像权与深度伪造风险，需要本人授权。
- 本技能产出的是"虚构人物的写实国风形象"，属创作内容。
- 朝代形制信息为常见复原流派的主流共识，严谨考据场景需另行核实博物馆与文物资料。
