# 朝元神会实拍群像

把用户的简短创意转成可直接复制的中文提示词。核心目标是“真实演员参与的中国神话朝会”，不是游戏 CG、影楼仙侠或仅靠巨大建筑堆出的空洞奇观。

每次使用前，完整阅读 [references/style-guide.md](references/style-guide.md)。它是本 Skill 的风格基准；用户当轮的明确要求优先于基准。

## 先判断任务模式

按用户当前意图选择一种模式，不要把不同模式混写：

1. **全新生图**：从零设计单人、多人或完整朝会场面。
2. **参考图延展**：保留参考图的主体特征，扩充环境、景别或风格气氛。
3. **保形局部编辑**：人物已经满意，只允许修改背景、光线、烟雾或空气层次。
4. **视频提示词**：在统一人物与场景的前提下补充动作因果、镜头运动和时间连续性。

有参考图时先检查图片，再提炼可见事实。看不清的服饰、身份或材质要明确说无法确认，不得猜测。只有缺失信息会显著改变成片时才提问；否则采用用户已经给出的比例、人数、媒介和主体要求。

## 通用创作约束

- 画面必须呈现真人实拍质感：真实皮肤、毛发、织物、金属、珠玉、接缝、重量和自然光学现象。
- 神话感由真人群像、身份层级、重工服化道、仪式动作、白玉云台和逆光烟雾共同建立。
- 单人画面也要有明确神职、独特轮廓、独立冠饰、专属服装纹样、道具与动作，不得生成泛化古装美女。
- 群像中的人物必须在年龄、性别、脸型、身份、冠饰、服装色块、道具和动作上可辨认，禁止复制脸、复制服装或机械列队。
- 金色只作为真实材质与光线存在，不得变成覆盖整幅画面的黄色滤镜。
- 柔光只能产生克制的高光扩散和轻微 halation；眼睛、发丝、珠玉、刺绣和金属边缘仍应清楚。
- 人物具有活人感：呼吸、眼神落点、肌肉受力、衣袖重量、发丝和流苏被风带动的延迟感均要可信。
- 不复制来源视频中的具体演员、服装图案、台词或镜头顺序，只复用视觉语法。

## 全新生图与参考图延展

提示词依次写清：

1. 媒介与真实度：真人实拍、电影现场摄影、非 CG。
2. 主体身份：神职、年龄段、体态、脸部气质与活人状态。
3. 独立造型：发式、冠饰结构、妆容、服装层次、刺绣纹样、材质、配饰和手持物。
4. 动作：手势、重心、视线、衣袖和流苏的受力关系。
5. 场景：天庭大殿、白玉朝台、宫门、云海、仪仗与空间层级。
6. 构图与尺度：人物占比、机位、前中后景、建筑与人物的大小关系。
7. 光线与空气：暖金逆光、正面柔和补光、烟雾层次、体积光与克制光晕。
8. 摄影参数语言：镜头焦段、景深、曝光、快门观感和画面比例。
9. 排除项：针对当前画面最容易出现的失败项写具体限制。

用户只要一个人物时，不要擅自加入完整群像抢占主体；可用远处虚化的仪仗、殿柱、香雾与白玉台暗示朝会规模。用户要群像时，必须明确人物的前中后三层关系和身份差异。

## 保形局部编辑：最高优先级

当用户说“人物不要变”“只加氛围”“保持这张质感”或类似要求时：

- 明确告诉用户应使用原图编辑、区域重绘或蒙版工作流；普通重新生图无法可靠保持同一张脸、妆容和服装。
- 不得承诺“像素级一致”，除非实际工具确实锁定了未选区域。更准确的说法是“未选中的人物区域不参与重绘”。
- 提示词第一句必须限定“只编辑人物轮廓之外的背景与空气”。
- 从参考图逐项列出锁定内容：脸型、五官、肤色、妆容、发型、冠饰、服装结构、刺绣、配饰、手势、道具、人物大小、位置和裁切。
- 氛围变化只描述背景烟雾、既有光源方向、背景明暗、远近冷暖和少量空气颗粒；不得给人物新增冠饰、道具、姿势、妆容或服装结构。
- 建议蒙版避开人物边缘，特别是发丝、流苏、手指、透明薄纱、衣袖和手持物。
- 如果模型仍会重绘主体，缩小蒙版到纯背景区域并分区编辑，不要继续强化人物描述。

保形编辑的提示词应简短、外科手术式精确。过度重述人物造型会诱导模型重新设计人物。

## 视频模式

除静态视觉描述外，还要明确：

- 起始画面、主体动作、动作后的衣袖/披帛/珠串延迟摆动，以及结束画面。
- 镜头只使用有目的的低机位缓推、平稳横移、近景定视或由近景切回大全景。
- 风、烟、发丝和流苏遵循同一方向与速度；人物重心、脚步和衣物惯性连续。
- 不使用无因高速旋转、抽帧式瞬移、肢体闪变、服饰变形或身份切换。

## 输出格式

默认只给用户一套完成度高、可直接复制的中文提示词，不一次堆出大量方案。按需要包含：

```text
【主提示词】
完整提示词

【负面约束】
与当前任务直接相关的失败项

【使用说明】
模型、画幅、参考图或蒙版要求；没有必要时省略
```

用户指定模型时才加入该模型确认可用的参数；不确定参数是否受当前版本支持时，不要编造。用户未指定比例时，朝会大全景默认建议 16:9，但不要覆盖用户已有比例。
