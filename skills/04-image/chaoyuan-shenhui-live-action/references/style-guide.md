# 朝元神会实拍群像风格基准

## 核心风格

真人实拍式中国神话朝元大典：数十位神仙以戏曲化冠饰和重工织绣礼服组成层叠群像，在暖金逆光、舞台烟雾与云海白玉台之间，以克制手势和轮番近景建立庄严、热烈的东方神会气质。

制作真人实拍质感的中国神话朝元大典，而不是 AI 概念图、游戏 CG 或现代仙侠影楼照。使用二十至三十位年龄、性别、脸型和身份各不相同的成年演员组成高密度神仙群像；每个人拥有独立且可辨认的冠饰、肩甲、礼服纹样、色彩和仪式动作，避免复制脸、复制服装和整齐列队。

造型结合中国戏曲神仙扮相、民间神像、古代仪仗与架空天庭礼制：大型鎏金冠、凤冠、冕旒、道冠、珠串流苏、点翠色构件、玉石镶嵌、云龙肩甲、宽袖礼袍、织金披帛和手工刺绣边饰。材质表现为真实织锦、丝绸、金属薄片、珠玉、绒线和做旧皮革，保留接缝、重量、磨损与手工不规则感。

## 色彩与材质

- 朝元鎏金 `#C58A3A`：冠饰、肩甲、织金纹样与逆光高光。
- 仪典朱砂 `#A83A2C`：礼袍、披帛、旗幡和视觉节奏锚点。
- 神会孔雀青 `#2F6F68`：女仙礼服、玉石镶嵌与冷暖对照。
- 帝王明黄 `#D6A047`：中轴主神和高阶角色的身份色。
- 宝石翠绿 `#39765C`：冠饰宝石、珠串和小面积装饰。
- 仪仗靛蓝 `#264858`：官冠、内袍和群像冷色分层。
- 云台象牙白 `#E6D7BE`：白玉台、云雾、衣领和正面补光。
- 殿宇烟黑 `#1A1511`：深色木构、背景负空间和轮廓衬托。

颜色饱满但不霓虹。金色主要出现在冠饰、肩甲、纹样和光线中，不把整幅画面涂成单一金色。

## 场景与群像布局

场景采用天庭大殿、白玉朝台或云海宫门。深色木构飞檐和金色构件形成暗背景，远景可见被云雾分隔的仙山、宫阙和仪仗旗幡。

人物采用前中后多层半环形或错落站位，核心神祇位于中轴，左右文武、女仙、道者、神将和执幡侍从形成身份层级。大全景偏中轴对称，人物近景可使用非对称三角构图。烟雾位于下方前景，逆光位于人群背后；群像中每人的冠饰高度、服装色块和手势应不同。

默认画面比例为 16:9。结尾或完整定场画面应以白玉台、云海、仙山和完整仪仗恢复空间规模。

## 摄影与光线

- 建立镜头：贴近地面的 24–28mm 低机位广角，从烟雾下方仰拍群神，使高冠和人物轮廓压住天空。
- 人物亮相：50–85mm 中近景或特写，浅景深，眼神、冠饰、手部法诀和织绣细节清楚。
- 关系镜头：前景人物清晰，后景另一位神祇自然虚化。
- 收束镜头：回到广角大全景，展示朝元队伍在云海白玉台上缓慢行进。

光线以人物背后的单一暖金色强光为核心，配合烟雾形成明显但可信的丁达尔光束、轮廓光和轻微镜头光晕。正面使用柔和暖色补光，保证面孔、妆容和织绣清楚；阴影保持深棕和烟黑，不做死黑。

允许传统摄影柔光镜产生轻微 halation 与暖色高光扩散，但人物眼睛、发丝、珠玉、刺绣和金属边缘仍须清晰。不要用全局模糊冒充氛围。

## 人物表演与动态

人物表演庄重，带戏曲程式感但不过度舞台化。可使用拂袖、结印、扶笏、执幡、并肩侧望、缓慢转身和集体前行。

动作应体现真人重量：手势先行，宽袖、披帛、珠串和冠饰流苏随后产生延迟摆动；微风带动少量发丝和衣缘，人物胸腔有轻微呼吸，目光有明确落点。烟雾持续缓慢流动，逆光亮度基本稳定。

视频镜头以低机位缓推、平稳横移和短暂定格式近景为主。大全景与人物近景之间可直接切换，也可借前景衣袖、冠饰或烟雾的短暂遮挡完成自然转场。节奏前段宏大建立，中段连续角色亮相，后段仪仗大全景收束。

音响氛围可使用低沉堂鼓、铜锣、云板、编钟和唢呐长音；保留衣袖摩擦、珠串轻响与整齐脚步的现场感。

## 文字规则

画面文字不是核心元素，无必要时保持无字。需要角色题签时，使用画面左右边缘的竖排白色中文行楷或题签式毛笔字，轻微墨迹边缘，不遮挡人物面部与冠饰。正文或字幕可用思源宋体。禁止现代无衬线大标题、霓虹字和游戏 UI。

## 氛围关键词

威严、热烈、众神齐聚、民间神话、仪典秩序、真人鲜活。时代为架空中华神话，服化道借鉴传统戏曲、民间神像、古代仪仗和传统宫殿礼制，但形成原创组合。

## 必须避免

- 西式奇幻铠甲、欧洲宫廷、日式动漫和赛博霓虹。
- 仙侠网游 CG、霓虹法术、完全依赖特效的悬浮建筑。
- 统一网红脸、过度磨皮、蜡像皮肤和无生命表情。
- 塑料金饰、轻飘无重量的服装和印刷感刺绣。
- 复制群众、复制冠饰、复制动作和无身份差异的同款服装。
- 空旷无人、只靠巨大建筑制造神话感。
- 大面积冷蓝滤镜、现代影棚灯光和覆盖全图的单一金色滤镜。
- 模糊手部、错误手指、断裂道具、变形冠饰和珠串粘连。

## 设计原则

1. 神话感首先来自真人群像、身份层级和重工服化道，不依赖无边际数字奇观。
2. 每位神祇必须拥有独立轮廓、独立色块、独立冠饰和一个可读的仪式动作。
3. 逆光与烟雾负责塑造神性，正面柔光负责保留活人表情和服装细节。
4. 大全景建立朝会规模，中近景让观众相信这些神仙是具体、鲜活的人。
5. 金色是材质与光，不是覆盖整张画面的滤镜。
