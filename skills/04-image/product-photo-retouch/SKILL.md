# 产品实拍图精修（Product Photo Retouch）

## 定位与边界

- 本技能负责「**已经拍好的产品图怎么修**」：把实拍图整理成**可直接粘贴给图像编辑模型**的精修提示词（in-context edit / 产品区域重渲染）。
- 出图工具（用户指定）：**精修 / 编辑走 `nano-banana-pro`；从零生成新图走 GPT**。提示词按 nano-banana-pro 的调性写——指令遵循与结构保持强，可以把锁定项写得"硬"；但它**同样无法保证精细字标的像素保真**，故必须配合 `scripts/restore_regions.py` 的第二道保险。
- 与 `product-analysis-master` 分工：那个技能回答「产品是什么」，本技能回答「怎么修」。结构依据优先取自母版；若尚未锁定，按 `references/02-lock-checklist.md` 现场建立锁定清单。
- **只输出文字与脚本**，不生成、不修改、不渲染任何图片。
- 默认交付：① 结构锁定清单（含差异更正与无法确认项）；② 一键复制提示词；③ 若涉及字标 / LOGO，附回贴脚本的用法。合并为**一个 `.md` 文件**落盘并 present。

## 何时使用

触发词：精修、修图、去毛屑、去尘、去指纹、全新感、黑更黑白更白、像 3D 渲染那种、材质表现不好、保留背景 / 保留光斑、母版锁定后给提示词、字标 / LOGO 被改坏。

## 第一步：判模式（决定整套提示词的骨架）

| 模式 | 触发条件 | 任务类型必须怎么写 |
|---|---|---|
| **A 纯清洁编辑** | 只要求去尘 / 去毛屑 / 去指纹 | `clean-up EDIT ONLY`；禁重绘、禁重打光、禁重构图 |
| **B 清洁 + 影调** | 追加"全新感 / 黑更黑白更白" | 同 A，另加 `ENHANCE`（S 曲线 + 全画面去尘） |
| **C 产品区域重渲染** | 说"材质不行 / 要像 3D 渲染那种" | `RE-RENDER THE PRODUCT REGION ONLY` at photoreal CGI quality |

**C 模式的硬判据**：旧提示词里若含 `not a re-render`、`not a synthetic render`、`keep it a real photo` 之类的**禁重绘措辞，必须全部删除**——否则模型只做"搬像素 + 提对比"，材质永远上不去。这是"材质修不好"的第一根因。

## 第二步：字标 / LOGO 走两步法（本技能的核心，不可省）

**结论先行：任何图像模型都无法保证精细字标与 LOGO 的像素保真。** 只要"重绘"，字标就会改形或乱码——这不是提示词措辞问题，是能力边界。因此必须两步：

**第一步（尽力，在提示词里）——`PROTECTED REGIONS` 排除区**

把字标与 LOGO 声明为保护区，要求"如同编辑前就被挖掉"：区域内输出**必须与原图一致**，不得重绘、重排、平滑、锐化、清理；无法保证则原样保留。整段文本见 `references/01-prompt-template.md`。

**第二步（保证，在出图后）——合成回贴**

**路径 1（推荐，无需坐标）**：在 PS / GIMP 里把**精修图放在上层**、原图放在下层，给上层加**图层蒙版**，用小画笔在两处（环带上的字标、环内孔里的 LOGO）**涂掉蒙版**＝露出原图。30 秒完成，且天然对齐、无误贴风险。
也可以在任意画图工具里画一张"白底黑块"的掩膜 PNG，再用脚本的 `--mask` 走自动流程。

**路径 2（脚本，需要坐标）**：先用 `locate_ring.py` 定量定位环，再回贴。

```bash
# 1) 定位环（自动，带交叉验证与置信度告警），输出叠加预览供人眼复核
python scripts/locate_ring.py --image 精修图.jpg --verify-with 原图.jpg --out-prefix 环区 \
    --cx-range 0.52,0.68 --cy-range 0.50,0.68 --r-range 0.09,0.13

# 2) 回贴：一个整圆同时覆盖环带与环内孔（比分贴 annulus+circle 更省事、更不易漏边）
python scripts/restore_regions.py --source 原图.jpg --edited 精修图.jpg --out 成品.png \
    --match edited --circle 1133,840,228 --feather 16
```

- **成品尺寸以精修图为准**（用户明确要求）：交付默认 `--match edited`，输出与精修图同尺寸（生图工具常为 1920px 级），原图会被等比放大后贴回。若只想快速核对而不在意分辨率，可用 `--match source`。
- 坐标一律填在**输出画布**的坐标系里（`--match edited` → 填精修图坐标）。
- 支持 `--rect / --circle / --ellipse / --annulus / --mask`（可重复）、`--feather`、`--check`、`--grid`、`--match`、`--level-match`、`--sharpen-amount`。
  - **微距 / 斜视**下环被透视压扁成椭圆 → 用 `--ellipse cx,cy,ax,ay`（ax/ay 为半轴），不要用圆硬套。
  - **一个整圆/整椭圆同时覆盖环带与环内孔**，比分贴 `--annulus` + `--circle` 更省事，也不会在两块交集留下不一致的边界。
  - **放大倍率 ≥2× 时必加锐度补偿**：`--sharpen-amount 80 --sharpen-radius 2 --sharpen-threshold 4`。原图往往只有 1086px 级，而交付常是 1920px 或 **3584×4800（4K）**，贴回区被放大 3.3× 后明显偏软；USM 只改锐度、不改字形与位置。（`--level-match` 仍默认不用。）
  - **⚠️ 放大时掩膜必须同步外扩，否则会出现「双环」重影**（2026-09-23 真机回贴实测）：羽化是**绝对像素**，若掩膜边缘 ≈ 物体外缘，过渡带就压在边缘上，原图边与生成图边各掺一半。
    规则：**`mask_edge ≥ 物体外缘 + (2×feather + 15~20px)`**，把整条过渡带推到剪影**之外**（落在环边暗部，天然不可见）。
    实测：4096 输出下 `--feather 52` + 掩膜刚好贴边 → 重影；改成 `--feather 16` + 掩膜外扩 55px → 重影消失。
    **不要只按比例乘羽化。**
  - **只贴回最脆弱的字标区，不要整块贴回大面积的印刷面**：模型对**大号、清晰**的印刷字（盒面大字标、标签）通常保留良好，把整块印刷面从原图贴回反而会让该区域在大幅放大后明显变软。判断顺序：先放大 1:1 看模型有没有把文字改坏 → 改坏了才把该块 `--rect` 补进贴回范围。
- **接缝**：贴回边界用 **`--feather 16`** 即可（实测边界梯度能量低于邻居，肉眼无台阶）。半径余量必须同时满足两件事：**≥ 6–10% 外扩**（让边界落在环外暗部而不是切在金属环上）**且 ≥ 2×feather + 15px**（否则过渡带压在环边上 → 重影，见上方 ⚠️）。
- **`--level-match` 慎用**：它按贴回区外圈的分位点把原图影调对齐到精修图。本项目实测该区域"暗部接近、亮部差得多"，纯色调匹配会**把明亮金属环整体压暗**（斜率 ~0.58），画质得不偿失。默认不加；仅当接缝肉眼明显、且原图与精修图影调差距确实很大时才试。
- 贴回区域**不会带"3D 渲染质感"**（它就是原图像素）——这是保证字标 / LOGO 保真的必然代价，交付时要讲清。
- `zoom_grid.py` 出**放大 + 坐标细网格**，人工读数用（`locate_ring.py` 结果不可信时的退路）。
- `locate_ring.py`：定量定位环心与内外半径。评分只用「外缘一圈亮 + 内缘一圈亮」，**内缘半径独立搜索**（不按固定比例），并**强制输出叠加预览 + 双缘强度 + 置信度告警**；`--verify-with` 会给第二张图做交叉验证并报告两图是否只是等比缩放。实测在本项目图片上与原图独立拟合互相吻合（Δ≈1–3px）。
- 依赖 Pillow（numpy 用于 `locate_ring.py` 与 `--level-match`）。

## 第三步：提示词骨架（11 段，顺序固定）

完整可复制文本见 `references/01-prompt-template.md`。段序：

`TASK` → `HARD SCENE LOCK` → `PRODUCT LOCK`（结构 + 丝印 + LOGO 遮挡）→ `MATERIAL UPGRADE`（逐面 PBR）→ `REMOVE` → `HOW TO CLEAN` / `DO NOT interpret smooth` → `EXPLICIT EXCEPTION` → `PROTECTED REGIONS` → `BRAND WORDMARK LOCK` → `ENHANCE` → `MUST PRESERVE` → `OUTPUT` → `AVOID`

顺序不可换：**先锁场景与结构，再谈材质与影调**。把"提升质感"写在结构锁定之前，等于先给模型改结构的许可。

## 每次必做（硬步骤，缺一不可）

1. **先判两件"没有就写错方向"的事实**：
   - **壳内是否装着手机**（装机体 / 空壳）——决定环内孔"该看见什么"：装机体 → 机身背面 + 被环带部分遮挡的品牌 LOGO（锁"可见/隐藏分割"）；**空壳 → 壳背板 / 盒内衬 / 背景（必须写"不得补画手机、不得往孔里补 LOGO / 镜头 / 金属片"）**。两者禁令方向相反，判错必出凭空造物。
   - **背景纹理是否会被误当瑕疵**——长毛绒 / 毛毯 / 针织的绒毛**本身就是结构**，必须写明"绒毛不是毛屑，只清真正外来杂物"，否则"去毛屑"会把背景磨平。
2. **建立结构锁定清单**：逐件编号 `P-01…`，每件写数量 / 形状 / 尺寸比例 / 位置 / 朝向 / 凹凸 / 遮挡 / 材质外观事实。看不清的写"无法确认"，**不得补造**。检查表见 `references/02-lock-checklist.md`。
3. **与上一版逐条比对**，显式列出差异更正（`原写 → 实测 → 更正`）。同一批图内**各视角独立锁定**，不互推部件方位；**仅配色不同 ≠ 不同版本**。
4. **丝印与 LOGO 走专用条款**：一律引用 `references/03-wordmark-and-logo-locks.md` 的原文（含变体字标与机身 LOGO 遮挡的完整锁定），不凭记忆重写；并加 `PROTECTED REGIONS` 排除区。
   - **多载体（环上丝印 / 壳缘模压字 / 盒面印刷）分别核对**，不假设三处字形一致；外部来源不统一时用"照原样 + 双向禁止替换"的写法（见 `03` §一.4），并请用户确认后收紧。
5. **主动确认三件需求侧决策**（用户没说时按默认出，并在交付中显式标注可切换）：
   - 背景 / 道具：**保留**（默认）／替换
   - 手 / 人物：**保留**（默认）／去掉
   - 光面大面积倒影：**保留真实但清脏**（默认）／替换为影棚渐变反射
6. **交付时告知回贴步骤**：凡提示词含 `PROTECTED REGIONS`，必须同时给出 `restore_regions.py` 的命令行（含取坐标与最终回贴命令），并说明"字标 / LOGO 的最终保真靠这一步"。
   - **成品尺寸：以精修图为准**（用户明确要求）。回贴时用 `--match edited`，输出分辨率与精修图一致；不要默认压回原图尺寸。
   - **按形状选模型**：近正圆用 `--circle`，**微距 / 斜视下被透视压扁的环用 `--ellipse`**（用圆套椭圆会偏移上百像素）。
     **椭圆还会「歪」**——手持 / 倾角下的支架常是**旋转椭圆**，此时必须带上第 5 个参数：`--ellipse cx,cy,ax,ay,angle`（角度，度，逆时针为正；`--annulus` 同样支持）。轴对齐椭圆只能"要么包住但白贴回一大片，要么收紧但露一角"——**露出去的那一角会被模型重绘，字标照样毁**。
   - **环几何测量（实测可靠管线，详见 `references/04-lessons.md` §15）**：
     ① 环带颜色掩膜（`B−G>14 且 R−G>8`）；
     ② **中心用代数圆拟合（Kåsa）**，**不要用质心迭代**——掩膜里只要有第二个紫色小簇，质心就会漂到那上面去（实测 `(617,617)` 漂成 `(476,608)`）；
     ③ **外缘用"角度分箱 95 分位 + 圆周中值滤波 + 主轴投影"**得到外椭圆；**Kåsa 的 R 是环带中位半径，不能当回贴半径**（实测外缘比它大 15%）；
     ④ **别用 Fitzgibbon 直接法拟合椭圆**——本环境里广义特征值会崩成复数，产出垃圾结果。
   - **两个量化自检**（不读图也能判对错）：① 归一化半径 `rho≤1.04` 的环带像素占比 **≥96%**；② 用 `invert(原图)` 当 edited 跑一遍回贴，与解析椭圆掩膜比 **IoU**（实测 0.987），可验证角度符号/旋转方向没搞反。
   - **回贴后必须自检**：① 尺寸等于精修图尺寸；② 字标 / LOGO 与原图逐像素一致；③ 贴回边界无可见接缝。
     **推荐做法（不读图也能判）**：取"掩膜向内缩 2×feather"的核心区，验证
     `mean|成品 − 原图(缩放后)| < 1.0` **且** `mean|成品 − 生成图| > 3`（实测 0.74/8.26、0.84/4.73）。
     这一条能同时抓出「掩膜没生效」「坐标填错」「角度符号反了」三类错误。
   - **⚠️ 别用紫环「质心」判断对齐**（2026-09-23 实测被它骗了 ~100px）：氧化环的镜面高光会把紫掩膜打得粉碎
     （最大连通域只占 3%），生成图的紫色区域又比原图多 60~80%，质心被质量分布拉偏；**并集外接框同样不可信**（实测被污染撑到 `ay=588`，真值 460）。
     可靠判据是**射线扫外缘**：同中心下两图 `r(θ)` 的**中位差 ≈ 0 即无位移**（若有位移则所有方向同向偏）；实测本次生成图与原图外缘 `597/547 vs 595/545`，**根本没漂**。
     注意 `IoU` 只能看**峰值位置**，其绝对值低（~0.5）是因为氧化环本身不是紫色。
7. **落盘 + present**：一个 `.md`，上半为锁定清单，下半为代码块形式的提示词；成品图一并 present。
8. **拿原生分辨率的图**（做回贴/合成时必做）：用户对话里贴的图常被**上传管线压缩**（实测：用户实际出图 3584×4800 的 4K，我这边只收到 1433×1920）。要交付高分辨率成品时，**直接向用户要素材所在目录，从磁盘读原图**，不要用对话里收到的那份；尺寸与坐标都要按磁盘上的真实文件重算（坐标可按已知比例换算，并用 `locate_ring.py` 复核一次环心/半径是否吻合）。
   - **收到目录后先 `ls` + 读尺寸，再核对尾号**：用户替换成高清版时**文件名会整体变**（实测 `nMOu/ThUD/kGVu` → `gZm3/N7Za/e-sd`），旧尾号、旧坐标同时作废；**不要沿用上一次的尾号**。
9. **每张图必须带「原图尾号 4 位」标识**（用户明确要求，2026-09-23）：项目里原图都叫 `canvas-image-<随机串>.png`，**前缀完全相同、只有末尾几位可区分**，而用户的处理工具里显示的是文件名末尾 —— 只写「图①/图②/图③」他**认不出是哪张**。
   - **尾号 4 位 = 文件名去掉扩展名后的最后 4 个字符**（如 `canvas-image-_zPAle-ZZ-y_gbSEnnMOu.png` → **`nMOu`**）。
   - 交付里**三处都要写**：① 每个提示词的**小节标题**写成 `## 三、\`sG-q\` · 图C 提示词（……）`；② 文件开头的**图片对照表**（尾号 / 完整文件名 / 内容一句话）；③ 回贴命令的 `--source` 用**完整文件名**、`--out` 用 **`<尾号>_成品.png`**。
   - 一个批次一个**对照索引**：把所有交付批次与项目文件夹清单汇总成 `原图尾号4位对照索引.md`，避免用户来回翻文件。
   - 首次接触某项目时，**先例举该目录的文件名清单并确认尾号规则**，再落笔。

## 语言与格式

- 提示词用**英文自包含**（nano-banana-pro 对英文结构化提示词解析更稳）；中文只出现在锁定清单与说明中，不混入提示词。
- 提示词必须包在**代码块**里，便于一键复制。
- **提示词小节标题必须带原图尾号 4 位**（见"工作流"第 9 条）：`## 三、\`sG-q\` · 图C 提示词（……）`。
  只给「图A/图①」用户对不上号 —— 这是他明确提过的痛点。
- 负面约束写成 `AVOID` 逗号串；最关键的禁令用**全大写**（实测对模型约束力更强）。
- 需要"绝对不允许"的效果时，加**显式失败判据**一句（如 `Treat any output where Λ has become A as a failed result.`、`Regenerating or altering either protected region is a failed result.`）。
