# 结构锁定清单 · 检查表

> 用途：写提示词之前，先用本表把原图逐项过一遍。**未过表就写提示词，等于把结构判断交给模型。**

---

## 一、逐件拆解（每件必写 10 项）

对每个部件编号 `P-01…P-nn`，逐项填写：

| 字段 | 要求 |
|---|---|
| 数量 | 写明 N；**唯一零件必须写"某处 = 1，对侧 = 0"** |
| 形状 | 圆筒 / 圆角矩形 / 环带 / 薄板 / 异形 —— 用几何词，不用"简洁、科技感" |
| 尺寸比例 | 用**比值**（约平台宽度的 1/3），不虚构毫米数 |
| 位置 | 用**产品自身坐标**（机顶 / 机底 / 自身左侧 / 自身右侧），必要时补**画面钟点方位** |
| 朝向 | 轴向朝向哪个面 / 字头朝哪儿 |
| 前后顺序 | 在同组零件中排第几层 |
| 安装方式 | 嵌装 / 一体成型 / 粘贴 / 卡扣 |
| 连接关系 | 与相邻部件怎么接 |
| 凸起 / 内凹 / 悬空 | 沿外法线向外凸 / 向内凹 / 齐平 |
| 遮挡关系 | 被谁遮、遮住谁的哪一部分（**LOGO 与丝印必写此项**） |

**透明度分级**：直接可见 / 合理视觉判断 / 无法确认。**"无法确认"只能写无法确认，不得用"可能是""通常为"继续描述。**

---

## 二、必查的 9 个易错项

1. **透明件是否建立了深度层级**（最外层 → 透明层 → 内部结构 → 更后层）；开窗是真贯通还是实心。
2. **遮挡关系**：哪些部件在视线上重叠（尤其 **LOGO 与环带 / 支架**、丝印与前景区件）。
3. **唯一零件的数量与位置**（闪光灯、传感器、支耳、断口）。
4. **断口 / 铰链 / 卡扣**的方位：写"自身某侧"**并**写"画面约几点钟"，两者都给。
5. **字标逐字符核对**：有无符号替换、变体字形、被裁切的部分（→ `03-wordmark-and-logo-locks.md`）。**多载体（环上 / 壳缘 / 盒面）分别核对，不假设三处一致**。
6. **疑似"像灰尘"的产品纹理**：金属拉丝颗粒、扩散件内部晶格、织物织纹、透明件内应力纹 —— 这些**不是瑕疵**，必须点名禁删。
7. **画面中倒置 / 侧置的印刷内容**：保持原朝向，禁扶正。
8. **摄影内容 ≠ 产品结构**：高光 ≠ 银色零件；倒影 ≠ 孔洞；大面积环境倒影属摄影内容，**需向用户确认保留方式**。
9. **配色差异 ≠ 版本差异**：仅颜色不同时，结构锁定项与遮挡关系**按通用处理**；随图变化的只有配色。
10. **壳内是否装着手机**（**新增，必查**）：装机体 → 环内孔透见机身背面与（常被环带部分遮挡的）品牌 LOGO，须锁"可见/隐藏分割"；**空壳 → 环内孔透见的是壳背板 / 盒内衬 / 背景，须写"不得补画手机、不得往孔里补 LOGO / 镜头 / 金属片"**。两者禁令方向相反，判错必出凭空造物。
11. **背景纹理是否会被当成"瑕疵"清掉**（**新增**）：长毛绒 / 毛毯 / 针织这类背景，其**绒毛本身就是结构**；提示词必须写明"绒毛不是毛屑，只清真正的外来杂物"，否则"去毛屑"会把背景磨成毡。

## 三、与上一版比对（强制）

列出**差异更正表**，逐行写：

```
项 | 上一版写的 | 本图实测 | 处理
```

凡位置、数量、规格、拼写被更正过，必须在交付中显式说明——**静默修正等于让用户继续用错版本**。

## 四、需求侧三问（用户未说明时按默认，并显式标注可切换）

| 项 | 默认 | 可切换 |
|---|---|---|
| 背景 / 道具（包装盒、陈列物） | **保留** | 移除 → 属换景，另出方案 |
| 手 / 人物 | **保留** | 去掉 → 属换景，另出方案 |
| 光面大面积倒影 | **保留真实但清脏** | 替换为影棚渐变反射 |

## 五、交付自检（逐条打勾）

- [ ] 全篇未出现本图之外的结构（未按"这类产品一般都有"补造）
- [ ] 无法确认项已单列，且未被写进提示词的肯定句
- [ ] 唯一零件均写了数量与位置
- [ ] 每个透明件都写了深度层级
- [ ] LOGO 与丝印均写了**可见 / 隐藏分割**，且**位置条款在可见性条款之前**
- [ ] 字标为**逐字符核对过**的拼写（含符号替换）
- [ ] `MUST PRESERVE` 是 `PRODUCT LOCK` 的保持句式逐条转录，而非一句"保持产品不变"
- [ ] `AVOID` 只含真会犯的错，最关键的 3–5 项用全大写
- [ ] 提示词为英文、自包含、放在代码块中
- [ ] **每张图都带「原图尾号 4 位」**：① 小节标题（`## 三、\`sG-q\` · 图C 提示词（……）`）；② 文件开头的图片对照表；③ 回贴命令的 `--out` 用 `<尾号>_成品.png`
- [ ] 已把需求侧三问的默认与可切换项写进交付说明
- [ ] 未生成任何图片

### 若本单涉及回贴（`PROTECTED REGIONS`）

- [ ] 回贴命令已给出（含坐标、`--match edited`、`--feather`）
- [ ] **成品尺寸 = 精修图尺寸**（未被压回原图分辨率）
- [ ] **交付前自己放大关键区域验收**：① 字标 / LOGO 与原图逐像素一致；② 贴回边界无可见接缝；③ 环内孔没有凭空多出来的图形
- [ ] 旧版本成品文件已清理或明确标注作废，避免用户拿到错版本
