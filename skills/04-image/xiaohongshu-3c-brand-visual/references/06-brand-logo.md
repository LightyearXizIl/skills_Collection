# 品牌字标规范（MAGEASY）

**字标由使用者后期自行添加**。本文件规定三件事：出图时要留多大的位、后期贴哪个尺寸、用黑还是用白；素材与脚本为可选辅助。

## 素材

| 文件 | 用途 |
|---|---|
| `assets/brand/mageasy-black.png` | 浅底用，纯 `#000000` |
| `assets/brand/mageasy-white.png` | 深底用，纯 `#FFFFFF` |
| `assets/brand/mageasy-src.png` | 原始文件，勿改，作为字形唯一真相 |

原始尺寸 1437×203，纵横比 **7.08 : 1**，带透明通道。两版是从原文件 alpha 重着色得到，字形未被重绘。

## 放置规范

| 项 | 值 |
|---|---|
| 位置 | **固定左上角**，距左 8.9% 画宽，距上 6.7% 画高（两者相等，均为 0.089W） |
| 尺寸 | 宽 **26% 画宽**（可用区间 24–30%）；高度按 7.08:1 自动得出，约 3.7% 画宽 |
| 颜色 | 只有纯黑与纯白。背景明度 ≥0.6 用黑，<0.6 用白 |
| 不透明度 | 100%，不得设半透明 |
| 禁止 | 描边、发光、投影、渐变填充、灰阶、反白块底、旋转、拉伸变形 |

同一套图内，五张的位置、尺寸、选色规则必须完全一致——这是系列感的主要来源。

## 为什么必须后期压，不能让模型画

`MAGEASY` 是变体字标：两个 A 都是 **Λ**（无横杠的 lambda 形），字距紧、笔画粗。生成模型见到这个词会"规范化"成 `MAGEASY`，或在第三次生成时把 Λ 补上横杠，或在缩小后糊成一团。

因此：

- 提示词里**永远不写品牌名**，也不写 `add a logo`。
- 出图后统一用脚本压印，字形永远取原始文件，零漂移。
- 封面、内页、收尾一律同样处理，不因为"这张留白小"就跳过。

## 可选：批量压印脚本

手动在 PS / Figma 里贴字标是默认做法。若一次出几十张、不想逐张对位，可用脚本代劳：

```bash
# 自动选色
python scripts/place_logo.py --image out.png

# 指定白色、加宽到 28%
python scripts/place_logo.py --image out.png --color white --width 28
```

脚本按画布尺寸等比计算位置与字标尺寸，`--color auto` 时采样字标覆盖区的平均明度自动选黑白。用手工时，直接按上表的边距与宽度数值摆放即可，两者结果一致。

## 边界情况

| 情况 | 处理 |
|---|---|
| 左上被产品占据 | 不移动字标。改构图让产品让出左上 8.9% W × 12% H 的区域；若已出图，用后期把该区域压平或提亮 |
| 底部深色、顶部浅色 | 按字标**所在区域**的明度选色，不按整图平均 |
| 图极小（如九宫格缩略） | 字标可降至 22% 宽，但不得低于 20%，再小就失去识别 |
| 联名图 | 品牌字标仍在左上，联名标放右上，两者不并排、不叠压 |

## 自检（每次压完必看）

1. 逐字符核对：`M Λ G E Λ S Y` —— 两个 Λ 不得变成 A，不得多出横杠。
2. 缩放比对：把成品缩到 20% 画面宽，字标是否仍可辨认；不可辨认说明压太小。
3. 位置比对：与同套其它图的字标左边缘、上边缘是否完全对齐（差 1–2px 在视觉上就有跳动）。
4. 颜色：不得出现灰字标。若背景是中灰，二选一：提亮背景或压深局部，不要妥协成灰。
