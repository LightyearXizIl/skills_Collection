# 翻车清单与定点修法

按"症状 → 根因 → 修法"查。只修那一张图，不要整组重跑。

## 一、结构类

| 症状 | 根因 | 修法 |
|---|---|---|
| 镜头圈/开孔位置偏移，孔数不对 | 提示词先描述构图再描述结构，模型重新设计产品 | 把"保持结构与比例"提到段落最前，构图描述放后面 |
| 产品变胖/变圆，厚度失真 | 缺少绝对比例参照 | 加入"thickness relative to the fingers must read clearly"或指定 mm 与镜头直径比 |
| 磁吸环变成贴纸 | 未说明材质 | 写 `matte machined aluminum ring, 0.5mm raised, with a hairline chamfer` |
| 折叠处出现第三条折痕 | 模型对折叠结构无先验 | 改用图生图，源图给到折叠状态；或后期合成 |
| 字标/丝印变乱码 | 任何模型都画不准变体字标 | 后期回贴，见 `product-photo-retouch` 的 `restore_regions.py` |

## 二、光与色类

| 症状 | 根因 | 修法 |
|---|---|---|
| 暗场图发灰、没有纵深 | 只有环境光，没有方向 | 显式写 `single raking light from upper left at 20 degrees`，并写 `opposite side falls into complete shadow` |
| 材质纹理糊 | 光太柔或景深太深 | 加 `grazing angle`，收光圈到 f/2.8，纹理面必须正对光源入射方向 |
| 亮场图发黄发脏 | 白平衡漂移 | 指定 `warm off-white #E8E3DF`，不要写 `white background` |
| 橙色泛滥 | 品牌橙被当成主色 | 明确 `orange packaging occupying under 15% of frame`，其余全部冷调 |
| 渐变过多，像 PPT | 模型默认加渐变 | 负向词加 `gradient, glow, blurred color field`；色块要写 `hard clean edge` |

## 三、文字类

| 症状 | 根因 | 修法 |
|---|---|---|
| 出现假中文/假英文 | 没在负向词里禁止 | `text, letters, chinese characters, watermark` 必进负向词 |
| 留白区被填了装饰 | 模型不喜欢空 | 写 `upper 30% left completely empty as clean white space`，并在负向词加 `decorative elements in margin` |
| 后期加字后被产品压住 | 图层顺序错 | 文字层永远在最上；产品允许被字轻微压住时，只压边缘不压焦点 |

## 四、人物类

| 症状 | 根因 | 修法 |
|---|---|---|
| 手指数量错、指节断裂 | 手部生成通病 | 降低手的出镜面积（切到手腕），或改用"只出手背"构图；必要时整手后期合成 |
| 手持姿势违背物理 | 未指定握法 | 写 `fingers wrapped around the edge, thumb on the front face` |
| 皮肤塑料感 | 默认美颜 | 加 `natural skin texture, visible pores, no smoothing`，负向词加 `beauty retouching, airbrushed` |
| 人物抢了产品的注意力 | 明度对比失衡 | 背景比人物暗 1–2 档；人物衣着用中性色，不许出现与点色同色的衣服 |

## 五、版式类

| 症状 | 根因 | 修法 |
|---|---|---|
| 九图放一起像九个品牌 | 背景明度/色温不统一 | 固定同一组背景 token；出图后统一做一次 LUT 或曲线，把背景拉到同一明度 |
| 封面没有视觉焦点 | 元素太多 | 删到只剩：产品 + 一句主标 + 字标。其余全砍 |
| 主标读不完 | 字数超 14 | 拆成主标 + 副标；或把时间/数字提到主标 |
| 产品被裁得不舒服 | 无意识出血 | 出血要有理由：切在产品的"重复纹理段"，不切在功能部件（镜头、按键、转轴） |

## 六、平台类

| 症状 | 根因 | 修法 |
|---|---|---|
| 主图在信息流里被压字 | 安全区没留 | 顶部 ≥8.3% H、底部 ≥11.1% H 不放信息 |
| 主页缩略图糊成一团 | 对比度不足 | 缩到约 18% 画面宽自检：认不出产品轮廓就重做构图 |
| 一套图在不同设备上色差大 | 用了广色域未转 sRGB | 导出统一 sRGB，且避免高饱和纯色大面积平铺 |

## 六、模板级错误（90 张实测后补充）

| 症状 | 根因 | 修法 |
|---|---|---|
| PITAKA 方向越做越黑、越做越"官网" | 把官网 KV 当官号风格 | 官号深底只占 6/30；默认走同色场域，暗场仅用于沉浸微距图位 |
| 图拉斯方向背景太素 | 漏掉"产品色渐变"这个前提 | 背景取产品主色的高明度渐变，中心亮、边缘暗 1.5–2 档 |
| 一张图里两个模板打架 | 封面同时塞了排印与场景 | 封面只保留一个模板，辅助元素移到内页 |
| MOFT 方向背景上了色 | 用产品色铺底 | MOFT 背景恒近白（明度 0.83 / 饱和 0.08），颜色只交给产品 |
| 三家做出来长得一样 | 只抓了共性，丢了明度/饱和纪律 | 先定背景明度与饱和（A 0.55/0.20、B 0.63/0.27、C 0.83/0.08），再定构图 |

## 七、自检三步（交付前必做）

1. **缩略测试**：把每张图缩到约 18% 画面宽，能否在 1 秒内认出"产品是什么 + 主标说什么"。不能则重做构图。
2. **九宫格测试**：九张并排，是否像同一个品牌在同一天发的。背景明度差 >15% 则统一。
3. **文字区遮挡测试**：把小红书 UI 蒙层（顶部 8.3% H、底部 11.1% H、右下 11% W × 8.3% H）盖上去，关键信息是否仍可见。
