# 小红书 3C 配件品牌视觉

## 用途

把「一张产品图 + 一句卖点」转成一套可发布的小红书官号图片方案：选方向 → 选模板 → 定画幅栅格 → 写中文标题 → 出英文提示词 → 自检交付。

三家的真正分野**不在有没有人、是不是深色，而在明度与饱和的纪律**（实测 30 张/家）：

| 方向 | 参照 | 明度/饱和 | 卖的是什么 | 一眼可见的特征 |
|---|---|---|---|---|
| **A 材质叙事派** | PITAKA | 0.55 / 0.20 | 材料与工艺 | 背景是产品色的暗延展，产品与底同色系，靠材质差异分离 |
| **B 活力场景派** | 图拉斯 TORRAS | 0.63 / 0.27 | 功能与生活 | 饱和渐变底 + 大特写出血 + 四角固定分工（角标/栏目名/产品名/主标） |
| **C 极简排印派** | MOFT | 0.83 / 0.08 | 观点与设计感 | 近白底 + 双语混排 + 上下双格/色彩矩阵，颜色全交给产品 |

## 何时用哪个方向

按产品的**第一性优势**选，不按品牌偏好选：

- 材料/工艺能讲出故事（芳纶、碳纤维、凯夫拉纹、剪穗工艺、一体成型、0.99mm）→ **A**
- 功能必须被"用"出来才懂（支点、折叠、磁吸、充电、防摔、贴膜）→ **B**
- 靠配色/形态/联名取胜，或需要高频日更维持品牌人格 → **C**

一套九图允许「主方向 + 一张副方向」（如 A 打材质、穿插一张 C 的配色矩阵），但**封面只能用一个方向**，否则主页九宫格不成立。

## 工作流

1. **需求三问**（缺一不可，缺则先问，不要猜）：
   - 产品型号与最想说的一句话卖点是什么？
   - 这套图发在哪里：官号日常 / 新品首发 / 联名 / 投放素材？
   - 必须出现的元素：品牌字标、联名 Logo、价格、门店信息、合规声明？
2. **选方向**：按上表判定，并说明判定依据（一句话）。
3. **选模板**：读 `references/05-template-library.md`，从 19 个版面里挑 1 个封面模板 + N 个内页模板。**先定模板再写提示词**，否则会退化成"随手一张产品图"。
4. **定套组**：读 `references/03-copy-and-layout.md` 取九图结构，删掉不需要的图位，保留 ≥5 张。
5. **写文案**：按该文件的标题公式出 3 条候选，选 1 条；主标 8–14 字。
6. **出提示词**：读 `references/02-prompt-templates.md`，按「方向 × 图位」取骨架，替换 `{{}}` 槽位。提示词一律英文，中文只出现在后期排版层。
7. **生成与自检**：出图后按 `references/04-failure-modes.md` 逐条过，不合格只重跑该图位。
8. **留字标位**：左上角按 `references/06-brand-logo.md` 预留 `MAGEASY` 位（宽 26% W，距左 8.9% W、距上 6.7% H），出图时该区域必须干净、无产品穿入。**字标由用户后期自行添加**，技能不代为压印；`scripts/place_logo.py` 仅供可选批量处理。
9. **交付**：给「提示词 + 文案 + 版面坐标」三件套，写明哪几张后期加字、哪几张直出。

批量产出骨架时用 `scripts/make_promptset.py`：

```bash
python scripts/make_promptset.py --direction A --product "MagEZ Case 6" \
  --colors "black-grey / burgundy" --selling "0.99mm 超薄芳纶" --out set.md
```

## 硬约束（三方向通用，违反即重做）

- **画幅**：3:4 竖版，比例固定、像素不固定。画布尺寸由出图工具决定，任何 ≥1024 宽的 3:4 画布均可直接套用本技能的占比规范。主页瀑布流按 3:4 裁切，横图与 1:1 会被裁掉两侧；需要横构图时另出 4:3 供内页。
- **安全区**：四周 ≥8.9% 宽；底部 ≥11% 高、右下 ≥11%×8.3% 的矩形内不放关键信息。
- **所有尺寸一律用占比表达**（宽度百分比 / 高度百分比），不以像素写死；给出像素等价值时仅作换算参考。
- **单图单主张**：一个视觉焦点 + 一句主标。两个卖点等于没有卖点。
- **中文只做后期**：模型画中文必乱码，标题、价格、角标一律设计层叠加。
- **字标位**：左上角必须预留 `MAGEASY` 位，宽 26% W（区间 24–30%）、距左 8.9% W、距上 6.7% H，该区域内不放产品与其他文字。字标由**用户后期自行添加**，技能只负责留位；**绝不让模型绘制字标**——`MΛGEΛSY` 的两个 Λ 会被写成 A。细则见 `references/06-brand-logo.md`。
- **色彩数量**：主色 ≤3（背景 + 产品 + 一个强调色），强调色 ≤15%。
- **背景服从产品**：A 取产品色延伸，B 取产品色渐变，C 退回近白。禁止用与产品无关的品牌色铺满背景。

## 与其它技能的边界

| 需求 | 交给谁 |
|---|---|
| 先看懂产品结构、材质、卖点 | `product-analysis-master` |
| 已有实拍图，要修图/重渲染提示词 | `product-photo-retouch` |
| 要出小红书这套图的方向、模板、文案、提示词 | **本技能** |

涉及 LOGO、变体字标、丝印保真时，必须叠加 `product-photo-retouch` 的 `PROTECTED REGIONS` 与回贴流程——本技能不承担结构保真。
