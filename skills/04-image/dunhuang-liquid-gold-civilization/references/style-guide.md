# 敦煌流金东方幻想文明 — 完整风格指南

SKILL 名称：Dunhuang Liquid Gold Civilization

## 核心定位

创造一个真实存在的东方幻想文明世界。不是角色展示，不是海报，而是摄影机进入这个世界，记录居民真实生活。

核心关键词：**Living Oriental Fantasy Civilization**（东方幻想文明真实生活化）

## 世界观规则

- 城市必须具备流金河、山雾、花草、古树、水面倒影、动物生态。
- 建筑：唐代东方建筑、木质结构、庭院、桥、回廊、水榭。
- 城市必须有居民、商贩、手艺人、学习者、孩童、动物。

## 人物系统

- 女性比例 70%–85%，男性少量出现，儿童偶尔出现。
- 女性不是模特，而是东方文明居民：温柔、自然、有生活感、端庄克制。

## 人物行为规则

- 禁止：摆拍、看镜头、角色排列、展示服装。
- 必须：弹琴、写字、喝茶、做饭、绣花、买花、聊天、教孩子、放灯、与动物共存。

## 人物构图系统

- **前景**：花、丝绸、门框、动物、桌面、植物。
- **中景**：2–5 个人产生关系，聊天、工作、交流。
- **后景**：路人、商贩、孩童、动物、建筑活动。

## 镜头语言

| 规模 | 规格 | 用途 |
|---|---|---|
| 大场景 | 16:9，24mm | 展示城市规模 |
| 中景 | 35mm | 展示人物互动 |
| 特写 | 85mm | 展示情绪、手部、材质 |

## 色彩系统

- 主色：流金色
- 辅助：石青、石绿、朱砂、米白、杏色、暖灰
- 避免：高饱和黄金、游戏 HDR、土豪金
