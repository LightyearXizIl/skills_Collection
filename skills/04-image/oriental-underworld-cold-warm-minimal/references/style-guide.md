# 东方幽冥极简冷暖电影美学 — 完整风格指南

基于单张参考图提炼｜仅提取该图可见的视觉风格与构图规律

参考图：冷暖雾色、极简留白、单人侧身、黑色长裙拖摆、橙红地平光带

## 一、风格核心

- **核心气质**：唯美、空灵、克制、孤独、宿命、安静，不恐怖、不血腥、不惊悚。
- **视觉逻辑**：以「极简空间 + 单一人物 + 大面积留白 + 冷暖渐层 + 长裙流线」为画面骨架。
- **情绪优先于剧情信息**：画面先传达等待、离别、回望、沉静、无声的思念，再考虑叙事道具。
- **超自然感不依靠怪物、鬼脸或强特效**，而依靠雾、风、光带、空旷空间与人物姿态建立。

## 二、构图规则

| 项目 | 规则 |
|---|---|
| 主体数量 | 优先单人；双人时也要保持人物之间有明显空间距离，不做拥挤群像。 |
| 人物位置 | 人物偏画面一侧或中轴稍偏，不强求正中央；人物占画面约 25%–40%。 |
| 留白 | 必须保留大面积空旷天空、雾地、草地或无细节渐变空间，留白是情绪主体。 |
| 姿态 | 侧身、低头、微垂眼、安静站立、轻缓回望最合适；避免夸张动作和正面硬摆。 |
| 裙摆 | 长裙必须形成清晰的大流线，向画面一侧拖展，承担视觉引导线作用。 |
| 前景/背景 | 背景尽量简化，不堆叠复杂建筑与大量道具；若加入元素，应远、少、静。 |

## 三、色彩系统

- **主色**：深蓝灰、烟灰、墨黑、冷褐。
- **暖色**：橙红、琥珀、暗朱砂，只集中在地平线、雾层或局部轮廓光，不大面积铺满人物。
- **冷暖关系**：画面一侧偏冷蓝灰，另一侧偏橙红暖光，中间以柔和雾化渐层过渡。
- **饱和度**：整体中低饱和；暖色负责情绪爆点，冷色负责空间与孤独感。
- **禁忌**：高饱和大红、大紫、荧光绿、霓虹色、廉价恐怖片绿色光。

## 四、光影规则

- 主光来源应像低位地平光、余晖、远处火光或雾中漫反射，而不是硬质舞台灯。
- 人物脸部以柔和侧光或侧逆光塑形，亮部集中在额头、鼻梁、脸颊边缘、肩线和裙摆边缘。
- 背景光要形成「由暗到暖」的柔和弧形或渐变光带，避免硬边光束。
- 暗部保留层次，不死黑；暖光可在雾中形成柔软光晕，但不能形成夸张魔法特效。
- 整体光影应有电影海报感，但仍然保持柔软、安静、真实。

## 五、人物与服装

- 人物优先年轻中国女性，气质清冷、安静、克制，不做惊恐、狰狞、哭喊。
- 发型简洁：低髻、盘发、半束发或顺滑长发，发饰少而精。
- 服装结构强调「上收下放」：上身贴合或简洁，裙摆宽大、拖地、具有明显重量与流线。
- 推荐色：灰褐上衣 + 黑色长裙；或暗红上衣 + 墨黑长裙；也可少量使用灰白。
- 布料以哑光、轻纱、细绉、软缎、棉麻混丝为主；避免亮面舞台缎、塑料感和夸张仙侠层叠。

## 六、环境与可扩展元素

所有新增元素必须服从「少、远、静」的原则，不得破坏极简留白。

- 可加入：薄雾、低草、彼岸花少量点缀、远处水面、孤灯、残桥、远山、旧寺轮廓。
- 可加入：黑猫或白猫，但只作为画面边缘的安静见证者，不抢主体。
- 可加入：孟婆，但造型应安静、悲悯、克制，作为远景或次主体，不做恐怖老妪。
- 可加入：红线、纸灯、白纸鹊、风铃等，但数量要少，最好只出现一种核心符号。
- 不建议：拥挤鬼市、满屏符咒、群魔、骷髅、血迹、怪脸、大片墓碑或过度民俗堆砌。

## 七、镜头与摄影建议

| 焦段 | 用途 |
|---|---|
| 24mm | 大留白环境建立；人物很小，强调天地、雾场、远山、地平光。 |
| 35mm | 最适合主体与环境兼顾，保持人物侧身与长裙流线。 |
| 50mm | 中景人物情绪，背景仍保留冷暖渐层与环境留白。 |
| 85mm | 仅用于情绪近景，仍需保留柔和侧光和简洁背景，不做商业人像棚拍。 |

## 八、动态规则（用于图生视频）

- **风是主要动态来源**：裙摆先受风向外展开，再因重量回落；发丝、草尖、薄雾方向保持一致。
- 人物动作小而克制：低头、抬眼、微回身、轻抬手、停步、回望。
- 禁止夸张旋转、奔跑、跳跃、漂浮、法术爆发。
- 镜头运动以轻微横移、缓慢前推、低幅度绕侧为主，不能破坏极简构图。
- 环境动态应有惯性与余韵：雾继续流、裙摆继续回弹、草继续摇、光带保持稳定。

## 十一、调用原则

- 当用户说「调用东方幽冥极简冷暖电影美学」时，以本 SKILL 为视觉基准。
- 无论题材加入七夕、忘川、孟婆、黑白猫、红衣、荒寺等元素，都必须先满足：极简、留白、冷暖雾色、单一视觉主体、唯美不恐怖。
- 若新增元素与极简画面冲突，优先删减元素，不牺牲整体气质。
- 本 SKILL 来源仅为参考图的可见风格提炼，不自动加入其他项目规则。
