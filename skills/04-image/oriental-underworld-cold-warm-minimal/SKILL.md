# 东方幽冥极简冷暖电影美学

基于单张参考图提炼｜仅提取该图可见的视觉风格与构图规律

参考图特征：冷暖雾色、极简留白、单人侧身、黑色长裙拖摆、橙红地平光带

## 风格核心

- **核心气质**：唯美、空灵、克制、孤独、宿命、安静——**不恐怖、不血腥、不惊悚**。
- **视觉逻辑**：以「极简空间 + 单一人物 + 大面积留白 + 冷暖渐层 + 长裙流线」为画面骨架。
- **情绪优先于剧情信息**：先传达等待、离别、回望、沉静、无声的思念，再考虑叙事道具。
- **超自然感不靠怪物、鬼脸或强特效**，而靠雾、风、光带、空旷空间与人物姿态建立。

## 五条不可破的底线

1. 极简
2. 留白
3. 冷暖雾色
4. 单一视觉主体
5. 唯美不恐怖

无论题材加入七夕、忘川、孟婆、黑白猫、红衣、荒寺等元素，都必须先满足以上五条。**若新增元素与极简画面冲突，优先删减元素，不牺牲整体气质。**

## 工作方法

1. 先定主体数量与位置：优先单人；人物偏画面一侧或中轴稍偏，占画面约 25%–40%。
2. 保留大面积空旷天空、雾地、草地或无细节渐变空间——**留白是情绪主体**。
3. 姿态选侧身、低头、微垂眼、安静站立、轻缓回望；避免夸张动作与正面硬摆。
4. 长裙必须形成清晰大流线，向画面一侧拖展，承担视觉引导线作用。
5. 背景尽量简化，若加入元素应「远、少、静」。
6. 主光模拟低位地平光、余晖、远处火光或雾中漫反射，而非硬质舞台灯。
7. 暖色只占局部（地平线、雾层、轮廓光），不大面积铺满人物。
8. 焦段按用途选：24mm 大留白环境／35mm 主体与环境兼顾／50mm 中景情绪／85mm 情绪近景。

## 元素扩展白名单

可加入：薄雾、低草、彼岸花少量点缀、远处水面、孤灯、残桥、远山、旧寺轮廓；黑猫或白猫仅作画面边缘的安静见证者；孟婆造型应安静、悲悯、克制，作远景或次主体；红线、纸灯、白纸鹊、风铃择一。

不建议：拥挤鬼市、满屏符咒、群魔、骷髅、血迹、怪脸、大片墓碑或过度民俗堆砌。
