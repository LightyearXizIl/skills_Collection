# 通用产品外观结构模板

上传产品图后的分析输出模板。按品类选择字段，填入真实观察，不交付空白表、不要求用户自己填。不适用项目删除，关键不可辨项目标注待确认。照片来自多个型号时分组分析。

## 1. 产品整体概述

用一小段说明可识别的产品类别、整体轮廓、主色与辅助色、最显著的可见结构。型号或品牌仅在有可辨标识或用户提供时使用，并说明必要的来源区别。

## 2. 外观结构依据表

| 部位或维度 | 图片可见的外观细节 | 对应图片或视角 |
|---|---|---|
| 整体轮廓与比例 | 几何形状、长宽视觉比例、厚薄观感、对称性、边角过渡 | 文件名或图号 |
| 正面 | 面板、图案、可见部件、各部件相对位置 | 同上 |
| 背面与内部 | 实际展示的结构；未展示不推测 | 同上 |
| 左右侧与顶部底部 | 侧壁、包边、层次、边沿高低 | 同上 |
| 组成与连接 | 可见分件、接缝、缝线、铰链、拉链、扣件、提手等 | 同上 |
| 开口与镂空 | 形状、可见数量、排列、位置；有无覆盖只在可确认时写 | 同上 |
| 凸起与凹槽 | 高低相对关系、轮廓、过渡方式 | 同上 |
| 配色与分区 | 主色、辅色、透明或半透明区域、颜色边界 | 同上 |
| 材质观感与表面 | 哑光、亮面、织纹、皮纹、金属光泽等可见特征 | 同上 |
| 标识与文字 | 可辨内容、颜色、方向、位置、相对尺寸 | 同上 |
| 配件与包装 | 单独识别，不能算成本体的图案或结构 | 同上 |

只保留对该产品有意义的行，必要时按具体部件拆行。对于服饰可增加版型、领口、袖口、下摆；包袋增加包型、肩带、五金；容器增加瓶口、瓶盖和瓶身；家具增加承重支撑、桌面或坐面；数码产品增加按键、接口与面板。

## 3. 后续还原必须保留的特征

提炼真正决定产品身份的少量细节：整体比例、部件数量与布局、开口形状、配色分区、品牌位置等。不得把不确定项写成刚性事实。示例性的类别知识不能替代本图依据。

## 4. 必要待确认项

只列影响还原的重要缺口，例如透明板与镂空无法判断、微小文字不可读、背面未展示、多张疑似不同型号。可以说明需要哪一视角来确认，但不因这些缺口暂停已知内容的总结。

## 5. 可直接复制的外观描述

最后提供一个独立 text 代码块，写成连贯的产品外观依据，包含已确认轮廓、配色、各部件位置、材质观感、标识和结构限制。不要写新场景，不添加性能卖点，不隐去影响使用的重要不确定项。

如需换景，将确认的产品特征带入每份换景提示词，并按该张实际可见面筛选；例如不可把背面标志加到正面，也不可把内侧文字复制到外侧。
