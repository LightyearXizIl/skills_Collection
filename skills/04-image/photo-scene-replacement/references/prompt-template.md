# 完整提示词编排模板

以下为写作结构，不直接将方括号占位符交付给用户。根据图片填实，删除不适用的段落。按生图软件没有记忆、每张独立执行来编写：每张重复完整共享规格，不能用“同上”“保持同一场景”或“沿用上一张”代替具体约束。详细要求见 SKILL.md 的“每条提示词独立写全约束”。

```text
编辑上传的实拍照片 [准确文件名]，替换 [背景及明确授权更换的部分]。保留 [该图产品方向、大小、构图、比例]，输出 [原图比例或用户指定比例]。
如附有已确定的同组成图，以其作为场景外观和布局参考；当前原图提供产品角度、可见结构与握持或支撑关系。

【产品结构与摆放】
[写清该图结构、可见文字面、孔洞、透明区域和实体区域；保持实际接触及支撑，说明旧背景和倒影如何更新。]

【材质分区与可选换色】
[逐一写出当前可见部件的平滑度、纹理尺度与覆盖边界、光泽和高光表现；正反面独立核对，不将整个产品概括成一种材质。遵循 SKILL.md 的“材质分区与换色约束”。]
[仅换色时写明目标部件与目标颜色，保留原图微纹理、明暗层次和表面光泽，反射随新场景合理更新；排除孔洞与未经授权改色的透明区域。只有一张实拍时直接写全目标视觉定义，不要求额外参考图。]
[按当前图片风险明确禁止纹理越界、背景纹理迁移或错误粗糙感，不用新增颗粒和过度锐化制造材质。]

【手部与美甲】
[仅换手时保留：手型肤色、左右手、入画方向、拇指食指动作、辅助手指、遮挡、指甲形状长度颜色与饰钻、袖口。]

【统一场景与物体约束】
[声明各输入图分别用于产品结构、目标配色或场景外观；场景参考图不得改变产品轮廓、比例、角度和结构。]
[定义统一空间坐标或固定机位画面布局，并写明产品中心、朝向、接触面及原图像素占比；不得为展示场景缩小、拉宽、压短或补全原本被裁切的产品。]
[逐件编号写全唯一数量、真实型号或无品牌自定义款、形状与组成、设计尺寸、材质与表面处理、基础颜色、坐标、旋转方向、相互距离、接触或承托关系。]
[复杂或生活化场景写明非对称角度、松散路径、局部裁切和轻微使用痕迹，同时锁定物品数量与位置，不能只写“自然凌乱”或靠增加无关道具。]
[桌面需写形状、长宽厚、基础色、纹理方向与尺度、桌沿及桌角的露出限制；窗帘、墙面、地面和家具同样写清结构、尺寸、材质、位置与方向。不适用的物体不添加。]
[逐件说明当前机位的露出比例、从哪一侧裁切、遮挡关系和虚化程度。物体可在画外，但不得为入镜搬动、扩展取景或缩小主体；同组不增加或替换物品。]
[检查所有物体落在承托面内且不穿插；透明面、孔洞和反射中可见的物体沿用同一空间坐标与透视。]

【当前机位与光线】
[独立写全本图机位方向、高度、距离或焦段、画幅、裁切及景深；光源位置、色温、软硬与阴影方向。共享规格原样复用，变化项符合空间透视。]

【限制】
[明确本场景禁止变化的项目，例如桌形、材质、纹理尺度、桌角露出、窗帘款式及背景物位置；再列当前图片相关的结构与遮挡限制，如镂空填板、旧场景残留或手指穿模。]
```

## 规格检查示例

若自定义87键ANSI TKL键盘，核对61键主区＋16键顶排＋6键编辑区＋4键方向区＝87；完整键盘定义与当前裁切可见键数是两回事。

若键盘覆盖X=30—66厘米，鼠标覆盖X=72—78厘米，则两者水平间隔为6厘米。鼠标是否在某张照片里可见取决于机位，不以搬动鼠标来满足构图。

这些是校验方法示例，不是新任务必须采用的款式、坐标或尺寸。
