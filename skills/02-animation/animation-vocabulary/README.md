# animation-vocabulary

来自 [emilkowalski/skills](https://github.com/emilkowalski/skills) 的动画术语反查 Skill，把“那个弹一下的效果”之类的自然语言描述映射为准确的动效名称，方便与设计师或 AI 沟通。

## 使用

```text
用 animation-vocabulary 告诉我 iOS 拉到边缘回弹的效果叫什么
这个菜单打开时先缩小再弹出的动画术语是什么
```

它只负责命名与解释，不负责设计或实现动画。
