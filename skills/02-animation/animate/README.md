# animate

来自 [emilkowalski/skills](https://github.com/emilkowalski/skills) 的动画实现 Skill。它按“是否需要动画、目的、工具、属性、曲线、时长、中断和退出”的顺序，从零设计并写出可上线的动效。

## 使用

```text
用 animate 为这个弹窗设计并实现进入与退出动画
让这个拖拽卡片的运动可中断且有正确的反馈
```

Skill 会读取 `RECIPES.md` 中的实现配方。它不负责全库审计或只读评审；对应任务分别使用 `improve-animations` 和 `review-animations`。
