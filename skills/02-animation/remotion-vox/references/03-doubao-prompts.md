# 视频过场(豆包 / 即梦)—— 只在"必须真实感"时用

**判断标准**:这段画面,用代码画出来会不会很假?
- 会(真实车流、真实街景、真实人流、自然光变化)→ 用 🟡 生成。
- 不会(数字、图表、流程、文字、抽象形状)→ 用 🟢 代码画,**别浪费额度**。

大部分 beat 属于后者。

## 写提示词的三条规则

1. **只描述镜头运动和光线,不描述内容细节**。过场是背景素材,内容由上层 cutout/组件承载。
2. **明确"无主体、无文字、无logo"**。否则生成的画面会抢戏,和你的前景打架。
3. **时长写死 3 秒**。太长会拖节奏。

## 通用模板

```
<场景描述>,<镜头运动>,<光线氛围>,电影感,浅景深,
无人物主体,无文字,无logo,留白构图,4K,3秒
```

## 分场景示例

**城市街景过场**(讲车/出行)
```
夜晚城市主干道车流光轨,镜头缓慢向前推进,霓虹蓝橙色调,
电影感,浅景深,无人物主体,无文字,无logo,右侧留白,4K,3秒
```

**科技感抽象过场**(讲参数/芯片)
```
深色背景下的蓝色粒子流动,镜头缓慢横移,冷色调,
电影感,无人物主体,无文字,无logo,中心留白,4K,3秒
```

**工厂/制造过场**(讲产能/供应链)
```
现代化工厂自动化产线俯拍,镜头缓慢下移,冷白工业光,
电影感,浅景深,无人物主体,无文字,无logo,上方留白,4K,3秒
```

**自然/户外过场**(讲续航/路线)
```
清晨山路航拍,云海流动,镜头缓慢拉升,柔和金色光线,
电影感,无人物主体,无文字,无logo,下方留白,4K,3秒
```

## 接入流程

1. 在即梦/豆包网页生成、下载 mp4。
2. 丢进 `public/clips/`。
3. 在 `config.ts` 对应场景加:
   ```ts
   video: {src: 'clips/xxx.mp4', overlay: 0.4},
   ```
   `overlay` 是压暗程度(0~1)。前景有 cutout 就调 0.4~0.6,纯过场调 0.2。
4. 过场层的叠放顺序是 **背景 → 视频 → 组件 → cutout → 字幕**,不用手动管 z-index。

## 自动化(可选)

给 API key 后我可以全自动生成 + 下载 + 接入。没有 key 就手动两步,流程不变。

## 注意

- **免费额度有限**,别拿过场当主画面用,它是"垫底的氛围层"。
- 生成的 mp4 通常带水印或 logo,下载前确认是干净版本。
- 时长对不上没关系,Remotion 会按场景 `durationInSeconds` 截断。
