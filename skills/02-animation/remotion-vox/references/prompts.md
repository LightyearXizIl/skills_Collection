# 可复用制作提示

这些是工作提示模板，不是对当前任务的自动授权。

## 脚本拆镜

```text
把下面旁白拆成逐句视觉 beat。输出旁白原句、实际或待测时长、核心画面、层级、素材来源、事实来源。优先使用代码绘制图表和文字；没有来源的数字标成待核实。
```

## 场景实现

```text
在现有 remotion-vox 工程中实现这组 beat。保持当前背景、字体和强调色不变，只替换中景与前景。动画只使用 Remotion 的当前帧、spring 和 interpolate，不使用 CSS 动画。
```

## Cutout 动画

```text
让第一个 cutout 先弹入，后续主体每隔 0.15 秒进入。保持透明底和半调质感，并添加一致的橙红色偏移描边。不要改旁白时长。
```

## 数据段

```text
把这组已核实数据做成柱状对比或折线增长。显示单位和比较口径，动画与数值同步结束，结尾至少停留 0.5 秒供阅读。
```

## 渲染检查

```text
先 typecheck，再渲染 VoxVideo 到 out/video.mp4。检查开头、中段和结尾帧、文字溢出、黑帧、缺失素材、场景时长和旁白截断；只报告实际完成的验证。
```
