# 脚本表模板 —— 一句旁白 = 一个 beat

**铁律:先有这张表,才动手做画面。** 表格填完 = 片子做完一半。

## 表格列

| # | 台词(旁白原文) | 时长 | 视觉 beat(画面上发生什么) | 素材来源 | 组件/配置 |
|---|---|---|---|---|---|

**素材来源标记**(一眼看出哪些不用管):

- 🟢 **代码** —— 用组件库直接画,零素材。大部分 beat 属于这类。
- 🟡 **豆包/即梦** —— 需要真实感的动态过场,才去生成。
- 🟣 **你的图** —— 你的车/出镜照,抠图后当 cutout。
- ⚪ **半调 cutout** —— 需要生图工具预处理的人物/物体黑白半调 PNG。

## 填写原则

1. **一句旁白配一个 beat**。一句话里塞两个信息点,就拆成两个 beat。
2. **时长 = 朗读这句的实际秒数**。中文正常语速约 **4~5 字/秒**。写完全文自己念一遍掐表,别拍脑袋。
3. **视觉 beat 只写"发生了什么动作"**,不写具体坐标——坐标是 Studio 里调的。
4. **优先想:这个信息能不能用代码画?** 数字、对比、趋势、流程、时间线 → 都是 🟢。

## 完整示例:选题「为什么这台车能卖爆」

| # | 台词 | 时长 | 视觉 beat | 来源 | 组件/配置 |
|---|---|---|---|---|---|
| 1 | 这台车,三个月卖了十万台。 | 3.5s | 标题逐字蹦出,光标闪烁 | 🟢 | `typewriter` text="三个月,十万台" |
| 2 | 先看销量曲线——前两个月平平无奇。 | 4s | 柱状图四根柱子依次长起,数字滚动 | 🟢 | `barCompare` 四个月 |
| 3 | 第三个月,突然拐头向上。 | 4.5s | 折线画出+面积填充,第三个端点强调跳动 | 🟢 | `lineGrow` [12,20,35,78] |
| 4 | 拆开看,是三电系统的功劳。 | 4s | 四个方块依次点亮,最后一个变红 | 🟢 | `flow` 电池/电控/电机/700km |
| 5 | 而它的价格,只有竞品的一半。 | 5s | 车的半调 cutout 从右侧弹入,背后偏移红块 | 🟣 | `cutouts` accent:'block' |
| 6 | 所以问题来了:它到底怎么做到的? | 3s | 文字定格 + 红描边加粗 | 🟢 | `typewriter` |

**统计**:6 个 beat,5 个 🟢 零素材,1 个 🟣 需要你提供一张车图。总时长 24s。

## 导出成 config.ts

让我把这张表落进 `src/config.ts` 的 `scenes` 数组即可。每行 = 一个 scene 对象:

```ts
{
  id: 's2',
  durationInSeconds: 4,        // ← 表格里的"时长"
  component: {...},            // ← 表格里的"组件/配置"
  caption: '先看销量曲线',      // ← 台词(或精简版)
  // narration: 'scenes/s2/narration.mp3',
}
```

## 常见坑

- **时长不准** → 字幕还没读完画面就切了。解决方法:自己念一遍掐表,或先录好旁白看 mp3 时长。
- **beat 太密** → 一个 3 秒的段里塞了柱状图 + 三个 cutout,观众啥也看不清。**一个 beat 只做一件事**。
- **全是图表没呼吸** → 每隔 3~4 个信息 beat,插一个纯文字或空镜 beat 让节奏喘口气。
