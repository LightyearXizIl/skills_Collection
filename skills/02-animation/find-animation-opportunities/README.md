# find-animation-opportunities

来自 [emilkowalski/skills](https://github.com/emilkowalski/skills) 的只读动效机会搜索 Skill。它寻找真正能增加反馈、连续性或空间理解的地方，同时明确拒绝不该动画的内容。

## 使用

```text
用 find-animation-opportunities 看看这个界面哪里值得加入动效
找出这个工作流中能改善状态连续性的动画机会
```

它只提出包含具体数值的建议，不写实现；已有动画的修复应使用 `improve-animations` 或 `review-animations`。
