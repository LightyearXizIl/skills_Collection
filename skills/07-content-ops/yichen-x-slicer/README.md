# yichen-x-slicer

把一个公开 X/Twitter Post、Quote Post 或同作者 Thread 制作成经校验的 1080×1440 图片切片和成品 MP4，并按原时间线保留所选原生视频的声音。模板、依赖和输出验证见 `SKILL.md`。
