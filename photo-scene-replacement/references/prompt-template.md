# 完整提示词编排模板

以下为写作结构，不直接将方括号占位符交付给用户。根据图片填实，删除不适用的段落。每张重复完整共享规格。

```text
编辑上传的实拍照片 [准确文件名]，替换 [背景及明确授权更换的部分]。保留 [该图产品方向、大小、构图、比例]，输出 [原图比例或用户指定比例]。
如附有已确定的同组成图，以其作为场景外观和布局参考；当前原图提供产品角度、可见结构与握持或支撑关系。

【产品结构与摆放】
[写清该图结构、可见文字面、孔洞、透明区域和实体区域；保持实际接触及支撑，说明旧背景和倒影如何更新。]

【手部与美甲】
[仅换手时保留：手型肤色、左右手、入画方向、拇指食指动作、辅助手指、遮挡、指甲形状长度颜色与饰钻、袖口。]

【固定空间与物体】
[定义统一空间坐标或固定机位画面布局。]
[逐件完整写数量、型号或自定义款、形状结构、尺寸、材质颜色、坐标朝向、相互距离、承托关系。]
[物体可在画外，但不得为入镜搬动；同组不增加或替换物品。]

【当前机位与光线】
[本图观察角度及物体露出范围；固定场景光源，正确投影与景深；符合实拍的自然纹理。]

【限制】
[只列当前任务重要失误：产品变形、镂空填板、旧场景残留、背景搬动、环面文字混用、手指穿模等。]
```

## 规格检查示例

若自定义87键ANSI TKL键盘，核对61键主区＋16键顶排＋6键编辑区＋4键方向区＝87；完整键盘定义与当前裁切可见键数是两回事。

若键盘覆盖X=30—66厘米，鼠标覆盖X=72—78厘米，则两者水平间隔为6厘米。鼠标是否在某张照片里可见取决于机位，不以搬动鼠标来满足构图。

这些是校验方法示例，不是新任务必须采用的款式、坐标或尺寸。
