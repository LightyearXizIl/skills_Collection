# photo-scene-replacement

面向产品白底图、实拍图、多角度商品图和买家秀的通用 Skill。它会先基于图片总结产品外观、结构、配色、材质观感和关键保留项；需要换景或换手时，再生成组图一致、每张可独立复制的完整提示词。

## 使用

```text
上传产品图并说：总结这个产品的外观结构细节
使用 photo-scene-replacement，把这组商品图换成统一的居家场景并分别给出完整提示词
使用 photo-scene-replacement，保留产品和握姿，只替换手部与美甲
```

仅上传产品图时默认只做外观分析，不自动生成或修改图片。若明确要求直接改图，还需要当前环境提供可用的图片编辑能力。

## 依赖与许可

- 不需要 API key，也不包含 API key、token 或私钥。
- 分析图片需要当前模型或环境具备读取图片的能力；直接改图需要可用的图片编辑工具。
