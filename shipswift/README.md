# ShipSwift

来自 [signerlabs/shipswift-skills](https://github.com/signerlabs/shipswift-skills) 的 SwiftUI 配方 Skill，内置动画、图表、界面组件，以及认证、相机、聊天等模块的实现文档。

## 使用

```text
用 shipswift 给这个 SwiftUI 页面加入 shimmer 加载效果
用 shipswift 构建带 Cognito 登录的 iOS 应用
用 shipswift 列出可用的图表组件
```

Skill 会先读取 `references/index.md` 查找配方，再按需加载对应的完整配方文件。免费配方均已收录在本目录，可离线使用。

## 依赖与许可

- 免费配方不需要 API key；目标项目需要 Xcode、Swift 和 SwiftUI。
- 5 个 Pro 配方不在本目录中，需要另行购买 ShipSwift Pro，并通过 `SHIPSWIFT_API_KEY` 连接官方 MCP 服务。
- 本合集不包含真实 API key、token 或私钥。
