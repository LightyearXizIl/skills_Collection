# 朝元神会实拍群像

「朝元神会实拍群像」是一个中文视觉提示词 Skill，用于把人物、神仙群像、天庭朝会或参考图需求扩写为真人演员实拍质感的生图、局部编辑或视频提示词。它重点控制戏曲化神仙服化道、人物身份差异、暖金逆光烟雾、仪式动作和群像空间层级，避免游戏 CG、影楼仙侠、复制脸和全图金色滤镜。

## 使用

安装后可直接用自然语言描述需求，例如：

```text
用朝元神会实拍群像写一幅二十位神仙在白玉云台朝会的 16:9 真人实拍生图提示词
```

也可以用于参考图延展、只修改背景氛围的保形局部编辑，或补充动作连续性和镜头运动的视频提示词。使用参考图时应先让模型读取图片；直接生成或编辑图像、视频仍需所在平台具备对应能力。

本 Skill 不需要 API key。

## 内容边界

- 保形编辑应使用原图编辑、区域重绘或蒙版，不能承诺普通重新生图会像素级保持人物不变。
- 不复制参考视频中的具体演员、服装图案、台词或镜头顺序，只归纳并复用视觉语法。
- 模型和平台参数可能随版本变化；仅在确认支持时使用具体参数。
