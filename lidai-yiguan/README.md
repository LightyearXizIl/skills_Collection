# 历代衣冠

「历代衣冠」是一个写实国风人像提示词 Skill，覆盖先秦、秦汉、魏晋南北朝、隋唐、宋元明清、民国、新中式、现代时装和仙侠玄幻。它会把人物、具体服饰形制、发妆、环境、光影和镜头参数组合成中英混排的六段式提示词。

## 使用

安装后可直接用自然语言描述需求，例如：

```text
用历代衣冠写一个民国夜上海风格的旗袍女性人像提示词
```

Skill 会根据时代读取对应的 `references/` 参考卷，并主动避免常见的跨朝代服饰混搭。它不需要 API key；生成图像时仍需使用你所在平台的图像生成能力。

## 内容边界

- 默认只创作虚构人物，不把真实人物照片转换为国风形象。
- 服饰内容是常见复原流派和主流视觉约定的整理，不代替博物馆、考古报告或专业服饰史研究。
- Midjourney、即梦和 Stable Diffusion 参数是经验建议，可能随模型版本变化。
