# uiverse-galaxy

将 [uiverse-io/galaxy](https://github.com/uiverse-io/galaxy) 的社区 HTML/CSS 与 Tailwind UI 素材库适配为 Codex Skill。它帮助 AI 从真实上游路径选择组件，保留作者归属，并安全地适配到现有项目。

## 使用

```text
用 uiverse-galaxy 找一个有明确键盘焦点的科技感按钮
从 Galaxy 选一个 Loader，改成当前项目的 Token
审查这个 Uiverse 组件的语义、动画和可访问性
```
