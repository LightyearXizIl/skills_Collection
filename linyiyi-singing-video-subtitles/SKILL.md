# 林依依唱歌视频字幕

本技能整合现有字幕工具与用户提供的 `2026-10-19_v1_唱歌视频字幕流水线`，保留技能名以兼容既有调用。

## 开工条件

先读取项目根目录的 `HANDOFF.md`（若存在），以用户当次要求为准。确认以下参数；缺失或冲突时一次性询问，不从文件名猜歌名、条目或日期：

- 无字幕 MP4、干声 FLAC、完整带音乐版 FLAC 的绝对路径。
- 条目号、建档日期、正式歌名、用户提供的逐句歌词。
- 项目根目录，默认见 [本机环境](references/local-environment.md)。

本标准流程要求三份素材齐全。用户只给视频、需要换音轨或其他剪辑时，先说明缺失条件或范围差异，由用户明确选择处理方式；不伪造素材、不静默跳过对齐。

## 必须保持的行为

- 用户歌词逐字原样保留：空格（含全角空格）、标点、语气词、断句均不自动修改。疑似错字也先询问。
- ASR 只核对句数、句序和漏唱，不将其逐字时间戳直接用作字幕轴。按干声实测、听辨与抽帧裁决句首和拖腔句尾。
- 只加 `《正式歌名》`、`— 林依依` 和当前演唱句。保留画面、时长、速度、分辨率、帧率及原音轨；音轨必须流复制。
- 字体固定 `Noto Serif SC`。标题文字块在画面垂直中心附近；不擅自移到顶部。参数与避脸规则见 [生产标准](references/production-standard.md)。
- 默认复制原件并核验 SHA-256。只有具体任务明确要求移动归档时，才使用 `-MoveSources`；整合或安装 Skill 本身不授权移动媒体。不得覆盖不同内容、删除非空旧目录或处理项目之外的文件。
- 不下载模型、不以其他字体降级；环境缺失时报告实际路径和错误。

## 执行

先读 [生产标准](references/production-standard.md) 和 [本机环境](references/local-environment.md)，按 [S1–S8 操作流程](references/execution.md) 执行：

1. 探测视频与音频，建立基准；用 `scripts/archive_sources.ps1` 建项并校验归档。
2. 提取工作 WAV，用 `scripts/detail_and_corr.py corr` 核对偏移及相关度。弱相关不能自动得出零偏移；符号和判据见操作流程。
3. 用 `scripts/measure_timeline.py` 测连续发声段，结合实际演唱裁决逐句边界。`analyze_envelope.py` 仅辅助粗看。
4. 用 `scripts/transcribe_faster_whisper.py` 离线核句序，保留原始识别 JSON，不覆盖用户歌词。
5. 按 [时间轴 JSON](references/lyrics-timeline-schema.md) 写已复核轴，运行 `scripts/build_subtitles.py` 生成 ASS/SRT。必须提供原始歌词文本文件，用于逐句精确比对。
6. `scripts/render_subtitles.ps1` 在唯一 ASCII 临时目录加载 ASS 和指定字体，保留源音轨烧录到新文件。
7. `scripts/validate_output.ps1` 验证完整解码、视频参数、帧数、音轨 SHA-256 和成片 SHA-256；再人工检查标题、每句中点、拖腔与空白边界。
8. 补齐项目、素材、过程、歌词核对与发布文案。工具脚本复制入项目，不收录临时测试数据。

## 交付

- 最终 MP4、可编辑 ASS/SRT、原始歌词及带证据的时间轴/歌词核对稿。
- 项目清单、素材清单、生成过程说明、发布文案、剪辑规范副本、字体授权说明、检查图和自动验收报告。
- 明确自动验收、实际字幕检查及用户观看确认各自状态；未真实运行不得声称已通过成片验收。
- 公开歌曲词曲授权、上游 H3 时长异常和工程未留存的证据按实际情况记录；发布前自行确认词曲授权，不把字体许可等同于歌曲许可。
