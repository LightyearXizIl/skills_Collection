# 林依依唱歌视频生产标准

## 目录与命名

每条独立建为 `01_视频项目/YYYY-MM-DD_第XX条_歌名/`：

```text
01_项目说明/         项目清单、抖音发布文案、剪辑规范副本
02_输入素材/
  01_视频源/         歌名_无字幕版.mp4
  02_音频源/         歌名_干声.flac、歌名_完整带音乐版.flac
  素材清单.md、素材清单.json、工作流嵌入元数据（若实际存在）
03_生成过程/         YYYY-MM-DD_第XX条_歌名_生成过程说明.md（只放一份）
04_剪辑字幕工程/
  01_字幕与识别/     ASS、SRT、原始歌词.txt、歌词核对稿、时间轴、原始识别 JSON
  02_检查图/
  03_工具脚本/
  04_工作副本与备份/
  05_字体授权/
05_最终成品/
  01_无字幕版/       歌名_无字幕版.mp4（校验过的副本）
  02_字幕版/         YYYY-MM-DD_林依依_第XX条_歌名_免费商用字体字幕版.mp4
```

`archive_sources.ps1 -WorkspaceRoot` 接受包含 `01_视频项目` 的林依依根目录；也可用 `-ProjectsRoot` 直接传 `01_视频项目`，二者择一，避免重复嵌套。日期必须显式指定。

默认复制，保留原件；同名同哈希可复用，同名异哈希拒绝覆盖。只有具体任务明确授权移动时才加 `-MoveSources`，且仅限同盘普通文件。移动前后核验 SHA-256，并登记原路径。空旧目录仅在明确要求清理且确认位于指定项目范围内后非递归移除。

## 歌词与时间轴

用户提供的每行歌词是唯一正文：不得合并空格、去标点、改同音字或重新断句。没有歌词或正式歌名冲突时先问。ASR 原文另存，不替代正文。

- 连续发声段不等于一句；按内部换气、能量凹陷、基频变化和实际听辨确定句界。
- 句首以首个可信有声帧为参考，回退约 50 ms 覆盖辅音；气声不直接当起音。
- 句尾跟完拖腔，观察低阈值与稳定基频，再留 0.1–0.2 s 淡出余量；不能提前消失。
- 无能量凹陷的连唱，结合新音起点与听辨；秒/字只作辅助，不能按字数平均切分。来源执行包中的 0.3–0.45 s/字是历史片段经验，不能证明任意歌曲句界。
- ±0.05 s 是人工对齐目标，不是测量脚本自动达到的精度保证。句首不得晚于实际起音，句尾不得早于实际收音。
- `measure_timeline.py` 的低置信标记、段间重叠/异常、弱相关必须复核；不要把测量分段直接逐条配歌词。

## 固定视觉

实际视频分辨率写入 `PlayResX/Y`；以高度 `k = H / 2048` 缩放字号，不用宽高比最小值：

| 项目 | 公式/值 |
|---|---|
| 字体 | Noto Serif SC |
| 歌名/署名/歌词字号 | round(100k) / round(54k) / round(74k) |
| 歌词 MarginV | round(235k) |
| 标题位置 | x=W/2，y=round(0.479H) |
| 署名位置 | x=W/2，y=round(0.535H) |
| 歌词左右安全区 | 各 round(84 × W/1088) |
| 颜色 | 白色 &H00FFFFFF；歌词描边 &H58000000，阴影 &H68000000 |
| 描边/阴影 | 歌词 1.2/1.4，歌名 1.3/1.5，署名 1.1/1.3 |
| 字距 | 歌词/歌名 1.4，署名 2.1 |
| 片头 | 歌名 0–3.60 s；署名 0.12–3.60 s；fad(280,420) |
| 歌词淡入/出 | 默认 100/120 ms，逐句可在 80–100/100–200 ms 内裁决 |

1088×1440 对应歌名/署名/歌词 70/38/52，MarginV 165，歌名 y=690、署名 y=770。文字块中心约 50.7%，实际字体字形需要抽帧确认。

标题优先保持画面中心附近，不遮脸、不压口型。命中嘴部时，小幅下移使文字上沿在唇线下约 20–30 px，块中心维持 50%–53%；与歌词冲突才考虑小幅上移，块中心 y 不小于 0.45H。仍无法避让时才移出中心区并记录原因与实际坐标，禁止未经说明移至顶部 10%–20%。生成器允许传入已复核的两个 y 坐标。

歌词保持单行，不溢出安全区，不加底板、逐字变色、粗体、贴纸或水印。生成器仅检查文本和时间合法性；长句宽度必须以渲染检查图验收，不能靠字符计数声称不溢出。

模板见 [subtitle_template.ass](subtitle_template.ass)，生成器直接读取它，避免两套样式漂移。

## 音频与验收

干声用于测量，完整带音乐版用于核对，二者归档不代表替换成片音轨的授权。标准渲染保留原视频的所有音轨，以 `-c:a copy` 复制；不能为满足 MP4 容器自行转 AAC。编码无法流复制时报告错误，由用户选择处理范围。

自动验收要求完整解码无报错，分辨率、帧率、实际解码帧数与源一致，像素格式为 yuv420p，逐音轨 SHA-256 相同，记录时长差和成片 SHA-256。容器时长差的默认容差 0.05 s 只是技术容差，视频流时长/帧数也要查看，不用它掩盖截帧或音轨变化。

人工抽帧：标题 0.5/1.6/3.4 s、每句中点、起止与无字幕区边界、拖腔收尾；检查字形、空格、居中、单行、安全区与脸部遮挡。测 ASS 时 `-ss` 放在 `-i` 后，避免输入定位影响滤镜时间轴。已烧录成片可以用输入定位。

字体日志若没有 `fontselect`，不能据此判失败，也不能仅凭“Arial 不显示中文”证明字体。优先显式加载指定字体、读取字体内部名称，并结合渲染字形；无充分证据则记录无法确认。字体许可说明保留来源链接与核对状态：[Noto CJK](https://github.com/notofonts/noto-cjk)、[Serif LICENSE](https://github.com/notofonts/noto-cjk/blob/main/Serif/LICENSE)。不把“免费商用字体”文件名当作整首歌曲的授权结论。
